## Context

140条路由，120项共用工作台。潮汐仅用固定球体和附加对数仪表，演示缺失，空间没有可操作对象；旧测试的同源数字断言不能证明现象正确。

## Goals / Non-Goals

**Goals:** 建立可重复的全站风险筛查与逐项任务审阅队列；以潮汐修复验证入口、双视图操作、现象反馈与科学边界。

**Non-Goals:** 本变更不声称完成140项教师/学生复测，不强制每个平面/静态实验伪造动画，不将Newton潮汐近似冒充完整碎裂仿真。

## Decisions

1. 四层验收分别记录结果：自动巡检、科学现象联动、学生任务、教学复核。自动化运行全量路由；未人工审阅状态必须保留。
2. 筛查遍历所有模型的非时间控件端点与情景；分别比较数字、去掉文字的主图、非label空间几何，并记录画面不变风险。三维直接操作的缺失是审阅项，不自动判定数学平面构造错误。对20项专用实验复用专用流程，不以通用适配器冒充完成任务。
3. 潮汐按原公式计算；距离对数映射用于屏幕布局，两个视图同源。半径示意放大，力箭头对数缩放且明确说明。显示Roche边界与独立的局部力比，禁止将二者阈值混同。小球保持球形，不捏造真实形变/碎裂。
4. 独立于物理时间的距离扫描，近处停止；演示明确不计任务，暂停/单步/减少动态/隐藏页面均可用。切换维度保留参数。3D选中小球才修改距离，空白拖动才旋转，键盘有同等参数控件。
5. 报告存JSON和Markdown，异常不吞掉；输出非零失败用于功能门禁，风险和待复核单独列出。浏览器截图/视频与独立科学比例断言结合。

## Risks / Trade-offs

- [几何签名不等于教学效果] → 仅作为风险信号，不能出具教学合格证。
- [共享工作台影响其他实验] → 新字段可选，运行原共享工作台回归。
- [空间拖动与相机冲突] → 仅命中可操作对象时捕获指针；释放/取消时恢复相机。
- [全量过程耗时] → 单次生产构建、独立路由测试和可筛选重跑；不重建运行中的构建。

## 本轮追加范围

按用户要求处理全量巡检发现的问题，逐项保留原始60条线索及处理证据。实际学生任务与教师教学复核延后至推广反馈阶段，不作为产品实现验收阻塞。静态不变量必须解释原因并验证适用条件；受力、热量、频谱和测量尺度可以作为科学证据，但不得伪造装置形变。演示明确区分参数扫描与物理时间。巡检增加过程状态，保留原始几何风险与科学证据判定，不通过删除原始报告消除问题。

## 回归中发现的问题

- C10将色块展开成数千网格，改为保留顶点颜色的单批次绘制；不改变像素数据和谱计算。
- 移动端悬浮观察窗避让同时处理range和select；用真实焦点和键盘操作回归。
- 潮汐的Roche标记与力箭头不接收指针事件，只由天体命中区域操作距离；覆盖标记线与天体重合的边界。
- 新测量标签在三维中使用明确列宽与字号，避免长单位侵占相邻读数。
