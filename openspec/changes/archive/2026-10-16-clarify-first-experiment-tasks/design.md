## Context

工作区已有透镜、重心、纸带的归档成果。报告推荐推广学习闭环，但角色反馈是推演。此次实施目标为浮力、单摆、截面、月相及透镜的窄范围连接改进。完整后续顺序见 `doc/student-feedback-work-plan.md`。

当前代码依据：浮力 `src/lib/stem-lab/buoyancy.ts` 将浸入量夹在0–10 cm；单摆模型已插值同向过零并计算周期，但只保存最近时间和周期；截面脚本 `src/scripts/exploration/section.ts` 渲染两图且未关联原棱；月相挑战只检查当前参数和食类型；透镜已有首次成功文案与六组记录处理器。

## Goals / Non-Goals

**Goals:** 一个首次动作、可定位的观察证据、操作旁的必要术语、演示与自主操作的来源区别；单摆两组测量能说清比较条件。维持实验各自风格与科学模型。

**Non-Goals:** 全站持久记录架构、三体同刻停止、手机布局全面重排、所有迁移题和新物理模型属于后续批次。首次任务完成不等于学习掌握。

## Decisions

### 1. 任务层与模型层分离

每页保持现有科学模型和自由操作。任务状态使用未开始/进行中/观察就绪，来源区分用户动作、准备条件、预设、演示、恢复。只有任务开始后满足本页有效动作与模型判据，才显示独立观察就绪。单纯输入事件不足以判断：预设赋值、演示写值、恢复都须显式标记来源；准备任务清除旧完成，手动接管只验证接管后的动作。

第一目标分别为：浮力只拖浸入量，看浸没部分与排水体积；单摆释放一次，看两次同向过零怎样量出完整周期；截面先选一个现有顶点，找到它来自哪条原棱，再进入五边形探索；月相固定满月，只转交点找地影；透镜沿用只移光屏调清晰。次级任务在首次目标之后邀请，不同时突出五边形、三种周期任务等多个入口。

浮力/截面等不必新增评分按钮：提示“这组可用于解释”，不声称“你已掌握”。复杂统一步骤引擎会使不同装置互相牵制，第一批采用页内小状态与共享文案约定；待真实接入差异清楚后再提取通用组件。

### 2. 浮力先澄清现有范围

首次行动保持液体密度不变，仅改浸入量；使浸没部分与 V排 对应。装置旁说明滑块控制的是0–10 cm浸入长度，不能继续改变完全浸没后的深度。完全浸没后浮力不再随深度变化作为模型推论呈现，不能包装成已完成操作证据。保留 g=10 与单位；底部压强若指水槽底，不能改称物体下表面压强。

考虑过扩大滑块行程，但这涉及物体上/下表面深度、水位与位置同步及上下压力差，需要独立科学验收。本批明确边界即可解决页面能力与文案不符。

### 3. 单摆从实际过零事件生成计时证据

保留现有插值时间算法；在测得新周期时保存该对同向过零的 t₁、t₂、方向和实验条件，供卡片与计时标记显示。开始/结束来自模拟时间，不能用动画进度或 performance.now 推算。反向过零不结束周期；尚未形成有效时间对时保存按钮不可用且解释原因。

两组快照显式保存，保留最近两组并在替换前清楚提示；包含摆长、质量、重力、释放角、阻尼、过零时间和实测周期。编辑参数/重新释放/拖球使当前测量失效，已存快照仍标注原条件；暂停保持时间对，继续接着测。比较输出全部固定量/改变量，多变量变化不能归因于单一因素。无阻尼完整理论值与小角近似维持区分；有阻尼注明理论仅参考。

### 4. 截面交点携带来源

由几何求交阶段将每个唯一交点关联原棱 ID 集合，来源随截面排序一起移动。经过原顶点时一个几何点可对应多条棱，不能靠展示层最近距离猜来源。正视图编号、投影视图交点、原棱和可聚焦按钮列表共享选择状态，触屏点击与键盘选择等效。平面变化后重建映射并清理失效选择，避免旧编号指向新顶点。

共面棱应标为整条棱落在平面内，其端点及相邻棱关联按模型明确呈现；点/线退化不标面积多边形。选择说明包含文字和形状/描边，不能只换颜色。使用旁侧编号按钮避免只依赖 SVG 小点命中，保留自由探索与五边形挑战。

### 5. 月相用不变条件构造可解释任务

任务准备为 phase180°、node90°、inclination5.145°、distance60.27 R⊕。明确两个交点是轨道穿过黄道面的位置，并在二维、三维显示一致编号。第一目标固定满月、倾角、距离，仅改变交点；检查采用 solveMoon 的本影判据，不硬编码“只在0°通过”，另一等效交点同样可成立。

准备、演示或预设不算独立验证。进行中的任务若选择演示/预设/恢复则退出独立验证，提示重新准备；改变固定量给出具体原因并要求重置任务，不允许隐含多变量成功。演示暂停/手动接管维持现有行为。旁边说明教学快照不作日期预报，展示比例与计算比例分开。

### 6. 透镜复用记录动作

首次手动调清晰后显示就地记录动作，与原记录按钮共用一个处理函数，遵守六组上限与存储失败反馈；不重复自动保存。再调焦入口可定位物距与光屏，不自动求解像面或改成已对焦。虚像说明可跳到现有眼睛观察窗，避免重新做一套虚像装置。保持刷新恢复、清空、两组比较与 reduced-motion 行为。

## Risks / Trade-offs

- [提示继续拉长页面] → 解释放在动作旁、按需展开；第一层只突出一个目标，C 批再凭任务基线决定布局。
- [独立观察误判为掌握] → 来源判据仅判断操作证据，迁移与真实学生解释单独验证。
- [过零显示与数值不一致] → 标记、时间读数、两组记录共用模型时间对，慢动作只改变播放速度。
- [退化几何来源错误] → 测试原顶点/共面棱/相切情形，按模型去重而非视觉归并。
- [存储入口重复导致重复记录] → 一个显式动作只写入一次，所有入口共用记录函数。

## Migration Plan

第一批没有存储格式迁移；透镜沿用现有格式，单摆两组仅当前页。先完成模型必要元数据与逻辑测试，再接页面任务层，最后做交互与已有流程回归。若撤回任务 UI，原自由探索仍独立运行；新增任务状态不写入原透镜记录。

## Open Questions

真实学生是否能从顶点来源与周期时间对形成解释、手机锚点是否足够、首次说明长度是否合适，均需试用。上述未知不阻止具体实现，但影响下一批优先级，不预设改善幅度。
