## Context

延续“预测 → 操作 → 观察 → 解释 → 再挑战”。电路是新领域，以六端口接线与两盏电阻灯为可控范围，支持任意端口对，不依赖固定串并联预设。

## Goals / Non-Goals

**Goals:** 学生能独立接亮、改变拓扑、拆灯验证另一支路、留两组可复现证据；所有故障与读数有一致模型依据。

**Non-Goals:** 通用 SPICE、交流、真实白炽灯温度模型、真实安全/器材指导、复制参考项目代码与素材。

## Decisions

- 参考 PhET 电路工具的接线/测量理念、Mathigon 的对象操作、Ray Optics 的案例进入、Polygons 的短问题节奏。GitHub 元数据及 README 在本轮读取，PhET README 声明历史仓库不维护，故独立实现纯 TypeScript 电阻网络。
- 电源电动势 E=3–9 V、固定内阻 r=1 Ω；灯 R=10–40 Ω，灯开关表示拔掉该灯支路，默认 6 V / 20 Ω。理想导线并查集合并等势点，剩余电阻用节点电压法与高斯消元求稳态。电源内部为固定 E 节点经 r 到 P，N=0；无锚点连通分量电势显示“悬浮”，不声称可量得绝对电势。
- 直接短接 P/N 时 I=E/r，不出现无限/NaN；外端电压与灯功率为0，能量耗于内阻。绕过一盏灯可使该灯0功率，不等同于电源短路。账本 E·I = ΣP灯 + I²r，可用来核验。
- 任意两端点点击接线，重复端点取消、重复线不新增；单独拆线按钮与清空/取消提供恢复。SVG 端口有原生 HTML 按钮覆盖，支持点击、触屏、Enter/Space，不要求拖动。
- 初次预接 P–A1，只缺回线。单灯/串联/并联示例明确标为示例并清除独立任务来源。独立任务从空板开始，两灯点亮后，亲手拔掉灯1，要求灯2仍有功率；验证独立支路还需模型反向断灯2检查灯1。电源内阻导致并联负载改变时亮度略变，不称为完全互不影响。
- 两组当前页记录存输入与接线；恢复后重算、取消选择、清除挑战状态，不伪造已完成。CSV 含模型版本、接线、E/r/R、开关、I/U/P 与单位。
- 视觉：淡蓝实验室背景 #eef6fb、午夜蓝电源 #153b56、瓷白灯座 #fff、铜色导线 #b86531、琥珀灯光 #ffc45b、青绿测量 #16766f。沿用 Noto Sans SC 标题/正文与 IBM Plex Mono 仪表。桌面“接线板 | 仪表”，手机仪表在板旁下方且读数与接线共处短工作台。记忆点是双灯亮度与带字母铜接线柱；不堆电子流装饰。静态光晕随计算功率变化，明确非光度标定。

## Risks / Trade-offs

- [浮空节点奇异] → 先分连通分量，只有有电势锚点的分量入矩阵；无锚点对外显示悬浮，电流0。
- [理想导线绕灯导致误诊] → 单灯0V与电源P/N同节点分开诊断。
- [并联“互不影响”过度表述] → 挑战只判断另一灯仍亮；说明内阻下端电压变化。
- [线交叉看不清] → 选中/取消明确，线两端在清单命名；交叉不自动连接，只有接线柱相连。任意导线电流不显示，避免理想零电阻环路不唯一的问题。
- [亮度误导] → 用功率作相对视觉提示，读数为定量证据；灯为恒阻模型。
