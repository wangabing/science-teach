## Context

面向青少年的透镜实验已有物理模型、三维/二维操作与观察窗。本轮遵循 doc/product-polish-benchmark-review.md 的顺序，先完成仪器操作标杆。

## Goals / Non-Goals

**Goals:** 清楚的首次动作，手机参数与视觉证据同屏，状态诊断，可恢复和比较的本机记录。

**Non-Goals:** 全站改版、账户同步、分享链接、重心与莫比乌斯实现、未经试用的教学效果结论。

## Decisions

- 入口提供“开始第一次调焦”，主动准备 f=10、u=30、s=8 的模糊状态；仍保留默认清晰静态图和自由探索。成功只由手动操作且模型 focused 判定，不由演示代做。
- 将预测、演示、情景和视角放入原生 details，首次任务和装置先出现。保留原按钮 ID、键盘与无脚本可读性。
- 手机控制区内放 sticky 光屏取景窗，复制当前投影几何并使用独立 SVG filter ID。比固定全页大装置更省空间；在控制区结束时自然离开。
- 视觉令牌沿用仪器蓝 #096dbb、光线金 #c58b16、纸白 #f7fbfe、标注墨 #153b56、刻度灰 #5b7588。标题和正文使用现有 Noto Sans SC，数据用 IBM Plex Mono。辨识元素是带实时状态的光屏取景窗，不新增装饰动画。
- 记录保存版本化 JSON 数值条件和延长线选项，不存 HTML 或推导结果；读取时校验数量、范围、步长与类型，恢复时取消演示、重算证据。重置和清空同步删除本机记录，提示文案明确。
- 最近两组列出固定焦距/物距/屏距和变化变量。只有焦距相同且物距变化、两组都已对焦实像时，比较物距与理论像距；其他情况只报告差异并提示控制条件，不自动声称因果。
- 诊断优先区分虚像、焦点、光屏行程，再区分目标像大小与未调焦。依据统一模型给出单条下一步提示。

## Risks / Trade-offs

- 本机存储可能被禁止或损坏 → 捕获读写异常，保留页面内实验，显示降级提示。
- 手机 sticky 遮挡 → 控制区限制、紧凑尺寸，在 320/390px 实测可见性和溢出。
- 刷新不会自动恢复当前装置 → 由学生明确选择记录恢复，避免隐藏初始条件变化。
- 两次记录不足以证明规律 → 文案只解释当前证据，真实 3–5 人试用仍需后续组织。

## Migration Plan

无依赖升级，独立存储键 v1；回滚页面与脚本即可，旧 JSON 不影响其他实验。

## Open Questions

首次操作耗时、停顿与教学理解需要目标年龄体验者观察，当前自动检查不能替代。
