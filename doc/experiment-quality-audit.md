# 140项实验逐项核查台账

与[修复说明](experiment-quality-repair.md)配套。每行对应一个实际路由，含本次主操作、空间表达、控件探测次数和三种截图。P/M/C/S分别为物理、数学、宇宙、工程；L为最早的独立实验。图集内以实验编号或slug标识，按从左到右、从上到下排列。

120个共用工作台共366个控件、732个上下界探测；此外核验装置旁主控件、历史展开、时间单步/播放/暂停、二维/三维读数与手机无横向溢出。最早20项由逐页双视图检查及专用旧流程回归共同验证。表中“观察”后的英文是数据指标的内部键；原始标签、单位和每次探测结果见[逐项JSON](assets/quality/audit-140.json)。
