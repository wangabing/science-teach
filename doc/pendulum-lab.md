# 单摆与能量实验

访问 `/stem-lab/pendulum/`。本地用 Node 24+ 执行 `npm run dev`，根据终端地址打开页面。浮力实验页页脚有入口，两页可互相跳转。

## 建议体验顺序

1. 抓住青色摆球，拉高并松手；空白处拖动旋转，滚轮或双指缩放。正面视角更容易操控，角度滑杆和释放按钮可替代拖拽。
2. 观察下方能量曲线：金色势能与青色动能交替，灰色机械能保持水平。暂停后使用单步或开启 ¼ 慢动作。
3. 开启对照摆，或点击三个探索问题自动准备实验。先预测，再用摆球运动、实测周期和受力箭头检验答案。
4. 把实验带到月球，观察更慢的周期；增加阻尼，观察能量耗散与摆幅减小。恢复地球、无阻尼，再对比 10° 与 70° 的周期。

## 操作约定

- 默认静止，不自动播放。「释放摆球」从设定角度重新开始，「继续」恢复暂停状态。
- 参数修改、拖拽和探索条件准备均清空旧曲线与计时，从静止开始新实验。参考摆同步重置，固定 1.50 m、1 kg、地球重力、35°、无阻尼。
- 实测周期由两次同方向过零计算，约在首次释放后的 1¼ 个周期出现。慢动作下显示的时间仍是仿真时间。
- 聚焦实验台，方向键旋转、空格开始或暂停；控件均支持键盘操作。页面隐藏时暂停；减少动态设置下可选择单步。
- WebGL2 不可用或上下文丢失时切换实时二维示意。拖拽与三维相机不可用，滑杆、模拟、对照、读数、能量图和教学仍可使用。

## 物理模型

摆球为质点，无质量不可伸长绳；二维竖直平面运动，θ 从竖直向下量起。

θ̈ = −(g/L)sinθ − bθ̇；h = L(1−cosθ)；v = L|θ̇|；U = mgh；K = ½mv²；T = mg cosθ + mv²/L。

采用固定 1/240 秒 RK4 积分，帧时间只决定推进多少仿真步。角度范围 ±70°，摆长 0.6–2.4 m，质量 0.2–3 kg，线性角速度阻尼 b=0–0.6 s⁻¹。无阻尼机械能恒定；耗散量按初始机械能减当前机械能计算。球体显示尺寸随质量变化仅用于辨认，不影响质点模型。

「完整理论值」用椭圆积分计算当前初始幅度的无阻尼周期，保留大角度效应；「小角度近似」为 2π√(L/g)。有阻尼时理论值只作参考。受力箭头是重力与绳子张力，共同比例；向心力不是第三个力。力较大时整体缩短两个箭头，保持比例与画面可读。

理想模型未包括刚体转动、空气非线性阻力、绳索松弛、悬点摩擦与碰撞。月球、木星选项只改变当地重力参数。无存储和后端 API。

## 验证

- `npm test`：包括 60 秒大角度能量守恒、实测/理论周期、质量独立性、摆长平方根规律、阻尼耗散和参数边界。
- `npm run build`：Astro 类型检查与静态构建。
- 服务器启动后运行 `npm run test:browser:pendulum`；可通过 `BROWSER_CHECK_URL` 指定地址。Chrome 验证真实拖拽、能量和周期、暂停/单步、探索反馈、参考摆、重力/阻尼、320/390px、减少动态、实时 SVG 降级和科学探索首页。截图输出 `test-results/pendulum/`。

Three.js 仅在实验路由加载。生产构建仍有部分脚本超过 500 KB 的体积提示。
