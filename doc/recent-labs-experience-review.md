# 近期实验共同体验审阅

日期：2026-10-16。范围：透镜成像、莫比乌斯带、重心与稳定、月相与日月食。按用户要求先完成月相内容，再进行共同审视和一轮可验证优化。评估来自真实浏览器、桌面/320/390 px 截图、模型与交互测试，尚无青少年参与者试用。

## 审阅原则
实验各自有合适的布局：光学台关注调焦、纸带关注连续追踪、倾斜装置关注释放检验、天文台关注空间与地球所见。共同的质量标准是能操纵、能观察、能解释，不强行统一作品模板。二维用于证据与可用性，三维服务空间认识；逼真材质不能替代正确的科学关系。

## 本轮发现与已实施
| 问题 | 证据与影响 | 已实施 |
|---|---|---|
| 三维标签过小或发灰 | 桌面场景截图中的接缝、G、焦点与月球字样不易读；浅背景字色偏淡 | Canvas 字体 32→48 px，明确 sRGB 与不受场景色调映射影响。标签保持各实验原有颜色和位置 |
| 手机参数与画面分离 | 350–390 px 长页面中，滚到滑块时装置已离开视野，改动后需往返寻找证据 | 四节共用精简实时观察条，仅在手机控件可见且画面离开视野时出现；镜像现有读数、一键回看画面并保留参数。画面/阅读/桌面阶段隐藏 |
| 天文俯视拖动方向不直观 | 原共享俯视相机的轻微 x/z 偏移让画面坐标斜转，Moon 拖动验收无法直接定位 | 本节使用不斜转的 astronomy-top 相机，保留其它实验相机预设；验证真实射线命中与拖动 |
| 手机全景太阳触到边缘，月球命中范围小 | 月相手机截图显示太阳边缘裁切，月球可见圆盘小 | 扩大本节取景留白，并加入透明拖动命中范围；大月盘仍在天空视图提供真实月面细节 |
| 红月只有效果，空间证据弱 | 单靠变红不能解释月球何时进入地影 | 新增同一比例本影/半影截面及覆盖百分比，并明确普通 k 与月食后的实际亮度不同 |

观察条内容分别为：透镜的像性质/理论像距、纸带绕行圈数/边界数、重心稳定余量/释放判定、月相受光比例/当前事件。它们不增加新的公式计算或持久状态。

## 后续优先级
| 优先级 | 工作 | 验收方式 |
|---|---|---|
| P1 | 找 3–5 位目标年龄体验者分别尝试“透镜调清”“纸带绕回起点”“展品运输”“满月找月食” | 记录首次可解释变化所需时间、卡住位置、是否能用读数解释，不把少量样本当统计教育效果 |
| P1 | 根据试用检验手机直接操作与滑块的往返成本，必要时为各题单独设计精简操作模式 | 用完成同一探究任务的往返次数比较方案，不再靠增加按钮解决所有问题 |
| P2 | 透镜优化光屏特写与虚像观察的视角切换提示 | 学生能分清理论像、光屏清晰度与眼睛观察虚像 |
| P2 | 纸带剪切增加逐段过程或沿剪后同一连通带继续追踪 | 能独立判断“一条/两条/套连”，不依赖颜色记答案 |
| P2 | 重心增加两组固定条件的并排证据对照 | 能解释同比加重不改临界角、降低配重会改变临界角 |
| P2 | 天文增加食季的时间关联或真实地表观察点专题 | 先确定历书与观察坐标模型，再给日期；当前快照不冒充精确食预报 |
| P3 | 三维分块与低端手机性能实测 | 记录冷启动时间、交互帧耗时和内存；不单用桌面无报错推断手机性能 |

本轮完成的是共同可读性与操作反馈优化。表中的后续功能仍是优先级建议，尚未实施，不能据此声称有真实教学效果提升。
