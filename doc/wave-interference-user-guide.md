# 双源波纹：两个波，能让这里安静吗？

日期：2026-10-16。入口：物理实验室 → 双源波纹，或 `/labs/interference/`。

## 开始探索

点击“准备静点任务”，中心探针、4 cm波长、6 cm源距与同相双源已准备好。先只改变第二源相位，观察整周期振幅。相位接近180°时，中心探针持续相消；不需要等动画偶然过零。改变其他条件会进入自由探索，不再计为这次独立任务。

页面默认静止。可主动播放、暂停，或单步推进0.05 s。切到后台会暂停，不自动恢复播放。手机上波纹图与相位滑块紧邻；减少动态效果不触发自动播放。

## 探针与证据

点击或拖动波纹台移动探针；聚焦十字探针后，方向键每次移动0.2 cm。也可展开“精确移动探针”，使用x/y滑块。

波峰为正位移、波谷为负位移，零位移不是光强，也不一定是静点。旁边独立显示整周期振幅，下方曲线显示接下来一周期的两个分量与合成：短虚线为源1，长虚线为源2，实线为合成。颜色之外可读距离、路程差与三项位移数值。

先用双源，再只开源1或源2，确认局部相消时每个分量仍可不为零。移动探针改变路程差；同样相位不保证所有位置同样安静。挑战后可回答“只看到一次0是否足够”，再用完整曲线检验。

## 记录与导出

“记下这组波纹”保留条件、探针、时间与数值，当前页最多两组；第三组替换最早一组，刷新清除。恢复A/B会暂停并重算读数，不计独立任务完成。两组比较列出所有变化，多变量改变不归因于单一因素。

CSV包含模型版本、模式、波长(cm)、源距(cm)、相位(°)、探针坐标(cm)、仿真时间(s)、频率(Hz)、单源振幅(mm)、两源距离(cm)、各分量/合成位移与合成振幅(mm)。英文表头自带单位，可用电子表格打开；不上传数据。

## 模型边界

单源振幅1 mm、频率1 Hz。u₁=A sin(2πr₁/λ−2πft)，u₂=A sin(2πr₂/λ−2πft+φ)。双源振幅 B=2A|cos((2π(r₂−r₁)/λ+φ)/2)|；静点任务阈值为0.1 mm。

这是已经建立的等振幅单频理想场，忽略径向衰减、边界反射和启动传播过程。固定频率改变波长，也意味着改变波速。没有模拟真实水面流体，也不由此推断真实能量输运或消声工程效果。Canvas不可用仍保留探针、读数与曲线；关闭脚本时保留静态解释与动手活动。

新增4项模型测试，覆盖同相增强、反相多时刻相消、空间路程差、瞬时零点反例、单源、CSV与非法输入。新增6项Chrome浏览器测试，覆盖独立任务、播放/暂停/单步/后台、指针与键盘、两组恢复/导出、320/390px触屏模拟、减少动态、Canvas失败、无脚本和目录入口。完整65项逻辑测试通过，生产构建生成20页。
