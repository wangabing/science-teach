## 产品变化与操作

- 首页四项起步作品：透镜、截面、月相、桥梁。推荐说明适合的问题、第一步和预期观察；推荐来自源码/作品结构审阅，不代表真实学生已验证吸引力。
- 全部实验保留140项。关键词支持名称、问题、主题和整理过的同义词，如“放大镜”；空间和探索目标可组合筛选，查找后地址可复制，浏览器返回会恢复筛选。目标只标注已整理作品，未标注不代表实验没有价值。禁用脚本仍显示完整目录。
- 六试点首屏提供“开始动手”：定位原始任务或控件，不自动执行任务。历史引子在短标题与时间中保留，展开可读完整背景与来源。
- 六试点新增“把这次发现，留给下次的自己”：先写预测、操作，再写解释并保存。保存当前条件和文字，最多两组；刷新找回后点恢复才改变装置。第三组替换最早一组。可清除本机发现。
- 新发现与原临时A/B记录、透镜六组记录分别保存。恢复暂停演示，重新求解；不恢复独立任务资格、未保存轨迹或已播放过程。存储不可用时明确提示当前页临时保留；记录损坏或模型版本不匹配时不应用条件。
- 短路线入口在目录前部。路线链接带上下文；共用实验也提供下一题，多路线时有选择。光路线改为透镜到双源波纹，明确从几何光学过渡到叠加模型。
- 每个试点有先修、直观/定量层、双视图职责和模型卡。个人解释只保存，不判分，不颁发掌握资格。

## 六项作品审阅

| 作品 | 关键动作及证据 | 两视图职责 | 科学核验依据 | 仍待验证 |
| --- | --- | --- | --- | --- |
| 透镜 | 独立移动光屏，比较两次清晰实像和焦点内虚像 | 空间装置位置/二维光路 | 薄透镜解析值、焦点边界；lens与lens-workbench测试 | 学生能否解释虚像与屏距 |
| 截面 | 选顶点找原棱，转切面找五边形 | 空间相交/正视截面 | 水平正方形与中心正六边形解析面积；exploration/first-task测试 | 能否自己说出边数变化原因 |
| 月相 | 保持满月只改交点，对照受光与本影 | 受光空间/地球所见和阴影截面 | 相位端点与独立月食几何；moon/first-task测试 | 是否改正月相是地影的误解 |
| 桥梁 | 亲手连杆，同结构变载荷，再拆杆 | 连接位置/二维受力与反力 | 整体力/力矩平衡、线性缩放与失稳边界；exploration测试 | 是否能设计和比较自己的方案 |
| 皮带 | 改轮径、播放，比较转速和扭矩 | 闭合装置/标记与比值 | 无滑动带速、转动功率；quality/experience-closure测试 | 是否理解功率没有放大 |
| 潮汐 | 拖小天体或改距离，比较两种加速度 | 空间距离/力与量尺 | 反三次方与自引力不变量；tidal-investigation测试 | 是否区分密度与材料强度 |

模型卡来源是公式/概念的具体阅读入口；界面的独立基准与回归验证不等于外部专家科学审查。所有课程匹配状态仍为未核实，未新增具体教材认证。

## 复现与证据

- `npm run review:index`：生成[140项资产索引](assets/product-improvement/asset-index.json)。未审阅状态不会自动变成通过。
- `npm test`：模型、目录与持久化校验。
- `npm run build`：类型与147页构建。
- `npm run test:browser:product`：自动启动生产静态服务；本机Chrome可设置`PLAYWRIGHT_CHANNEL=chrome`，外部服务用`BROWSER_CHECK_URL`覆盖。
- `BROWSER_CHECK_URL=http://127.0.0.1:4371 npm run test:browser:quality`：全站双视图、控件与手机回归。
- `node scripts/serve-dist.mjs`后执行`npm run measure:product -- after`：固定390×844、100ms延迟、200000B/s下载、4倍CPU减速、禁缓存，每页三次。改前产物测量保存为`performance-before.json`，不可用改后产物覆盖。

验证汇总、性能对照、截图与审阅结果在`doc/assets/product-improvement/`。最终运行结果见[验证记录](assets/product-improvement/validation.json)，性能见[前后对比](assets/product-improvement/performance-comparison.md)，手机首屏见[六试点截图](assets/product-improvement/screenshots/six-pilot-first-screens.jpg)；浏览器错误与失败修复保留在交付验证记录中。

## 实际验证结果

297项单测通过；类型检查0错误/0警告/0提示；147页构建成功。新增13项产品旅程通过；全站质量141个唯一用例经受影响项重跑后全部通过，140页历史在有/无JavaScript下均通过。既有透镜、首次任务/波纹、月相、六独立实验操作/教学、参数演示、潮汐和历史共8套影响范围回归通过。

目视审阅修复了潮汐新增浅色面板继承深色主题文字的问题；最终构建补跑13项产品旅程（含文字对比度）与9项质量用例全部通过。初次查找定位器歧义、重建期间临时404及中断采样的处理均保存在验证记录中；未将失败初跑写成全通过。

本机Node23.4.0、Chrome155，项目与新配置的CI要求Node24；本轮未在托管CI执行，也未发布上线。保留构建的大分块提示。所有帮助度、吸引力、教材适配与真实学习效果仍待推广反馈，不由这些自动检查推断。
