# 重心与稳定：操作指南

打开 `/labs/balance/`。默认居中配重、12° 倾角，松开夹持可以站住。画面金色 G 是架与配重的整体重心，金色竖直虚线交到台面；橙线围出原支撑面，旁边落点尺和稳定余量说明位置关系。

## 自己探索
1. 拖动蓝色配重上下/左右，或使用滑块。相机空白处拖动转动，滚轮/双指缩放；也可选正视、俯看。键盘聚焦画布后方向键转动视角。
2. 固定其它条件，提高配重，看临界角怎样变化。选择高处/低处对照，质量都为 4 kg，位置不同。
3. 增大倾角或收窄支撑，直到余量为负。夹持器此时仍保持姿态，点“松开夹持”才真正翻倒。
4. 释放中可暂停/继续。首次侧面接触台面时展示停止；点“扶正”保留参数继续比较。改变参数也会扶正重新夹持。
5. 切换二维可直接拖蓝色方块；聚焦方块，左右键横移、上下键改高度，每次 1 cm。微调按钮适合手机。

## 标准演示与挑战
“越过边缘会怎样”逐步增加倾角，越过临界后自动松开。“把配重放低”固定质量、宽度和 25° 倾角，只降低配重；先做预测，再用余量与临界角检验。不自动播放，手动改变条件会停止演示。

运输挑战要求在 20° 下保留至少 3 cm 稳定余量。准备后装置容易翻倒，可以降低配重、改变其位置/质量或加宽支撑；只减小倾角不能过关。方案通过后松开，检验是否站住。

## 读数与模型边界
正余量在原支撑范围内，负余量表示越过最近边缘；力矩正为恢复，负为翻倒。释放前判据在下方保留，释放后的时间/角度/角速度另行更新，不能用原支撑面判断落地后的新姿态。

模型尺度为米，架高 1.2 m、质量 2 kg，配重按固定点质量处理。只模拟防滑左右翻倒，不模拟滑动和反弹；临界平衡在没有扰动的理想模型中不会凭空运动。无 WebGL 自动进入同状态二维；无脚本可读静态图并按页面纸盒/硬币活动亲手验证。减少动态设置下直接展示释放的首次接触结果。
