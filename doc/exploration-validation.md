# 六个探索实验：验收记录

日期：2026-10-14。环境：Node 24.19.0、Astro 7.3.5、本机 Chrome / Playwright，生产静态构建由 http://127.0.0.1:4326 提供。

## 自动验证

- `npm test`：24 项模型测试通过，包含原有 7 项与新增 17 项。覆盖全等三角形刚性和面积守恒、拼图覆盖无重叠、三至六边形真实截面、三个周期的圆轨道闭合与能量守恒、碰撞和逃逸、三体能量/动量/质心守恒与独立对照、近遇初态 20 时间单位、桁架失稳/平衡/线性/偏心载荷、齿轮传动和功率比例。
- `npm run build`：Astro/TypeScript 0 错误、0 警告、0 提示，静态构建生成 15 页。
- `npm run test:browser`：首页、目录、浮力、单摆和新增六实验完整回归通过。旧浏览器断言中的实验总数由 2 改为 8；物理空间仍为两个实验。
- 最终布局修复后的 `npm run test:browser:exploration`：通过，含全页截图及 1440px ↔ 390px 切换不丢失拼图进度。
- `openspec validate add-six-exploration-labs --strict`：通过。

## 新实验浏览器验收

- 面积：真实指针拖动并吸附、错误朝向反馈、四块完成、参数变化重置、轮廓提示、SVG 键盘 Enter 放置；新增截图及响应式切换保留进度检查。
- 截面：三角形/四边形/六边形预设，63°/50°/0.4 的五边形、面外空截面。
- 卫星：500 次单步保持近圆轨道、播放/暂停读数保持、坠落与逃逸结束、重置恢复、后台标签暂停。
- 三体：零扰动完全相同，非零扰动独立演化；近遇预设的位置差、能量误差和重置。
- 桥梁：从裸框开始添加 A–E、C–E 得到稳定桁架；中央载荷反力、载荷加倍位移加倍、偏心载荷、键盘删除关键斜杆后失稳。
- 齿轮：三倍减速、加入中间轮后同向、改变中间齿数不影响输出转速、单步转动、默认重置。
- 所有六页：320/390px 无横向溢出、触屏按钮操作、键盘滑块、减少动态时默认暂停、禁用脚本时保留装置与原理；无页面 JavaScript 错误。

## 视觉复核与修正

截图在 `test-results/exploration/`，桌面六张、390px 六张、320px 六张。已检查数学、宇宙、建造桌面布局及手机布局。

- 拼块搬走后左侧保留淡色原拼法参考，右侧灰色区域明确表示待填位置，保证剩余黄色面积可比较。
- 齿轮使用贴合装置的视图范围，手机不再显示过小的齿轮；齿数、转速、方向放在独立文字区域。
- 全页截图临时改变布局会触发媒体查询；已将面积拼图切换布局的“重置”改为保留位姿、朝向与进度，旋转手机同样受益。

## 模型和体积边界

新增实验为教学 SVG 与纯模型，不加载 Three.js 或依赖 WebGL。各页脚本约 3–6 KB，公共交互模块约 1.2 KB（未 gzip）；首页未加载完整实验场景。

原有浮力/单摆共用三维包约 560 KiB，构建仍有超过 500 kB 的提示；它不由首页或六个新增实验加载。未修改构建警告阈值。

三体采用软化引力、固定步长与近遇/误差暂停；桥梁仅小变形线弹性桁架；齿轮理想扭矩不包含摩擦；卫星忽略大气和推力。相应边界写在用户页面与操作指南中，未将模拟读数冒充实际测量。
