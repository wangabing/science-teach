# 电阻分压台与电容时间台

日期：2026-10-16。新增两项原创电学实验，组成“接线工坊 → 电阻分压 → 电容充放电”的连续路线；目录现有16项实验，物理实验室7项。交互沿用控制变量、即时测量和两组证据的设计原则，未复制第三方代码或图形。

## 电阻：6 V怎样分出3 V？

入口 `/labs/resistors/`。点“准备分压任务”，上电阻从500 Ω开始，固定电源6 V、下电阻1000 Ω、负载断开。亲手把上电阻调到1000 Ω，输出达到3 V（允许±0.05 V）。仅改变上电阻仍可继续修正；更改其余条件、接入负载、示例或恢复记录会清除原任务状态。

记下空载条件，再接入1000 Ω负载：输出降到2 V，电源电流从3 mA升到4 mA，下电阻与负载各分到2 mA。两段电压条、空载参考、支路电流与功率账本由同一个模型重算。预测按钮只解释参考条件，不替换当前实验。

使用理想零内阻电压源、恒阻元件和直流稳态；不同于接线工坊的1 Ω内阻源。本页输出下降来自分压器的负载效应，不是稳压电源。未模拟温度变化、额定功率和测量误差。历史入口为欧姆1827年电路研究，页面列MacTutor参考链接。

## 电容：电源断开，电压还在吗？

入口 `/labs/capacitors/`，初始暂停。默认6 V、1000 Ω、1000 µF，τ=RC=1 s。点“单步1 s”，电压约3.793 V、电流约+2.207 mA。切“保持（开路）”：时间不跳、电压不跳、电流立即变0；再单步1 s，电压仍是3.793 V。切“放电”再推进1 s，电压降到约1.395 V，电流为负。

首次任务需要实际完成充至至少3 V、开路保持并推进、经电阻放电并推进。示例恢复不计为个人观察完成。更改任一参数会暂停，将时间、电压、曲线和累计能量归零，保留已存记录；可从同一起点对照。把电容改成2000 µF，同样从零充1 s，电压约2.361 V，τ为2 s。同电压下容量越大储能越多，同一时刻却不一定电压越高。

电压与有符号电流分别绘图，横轴为实际仿真时间，最多保留最近400采样点；切挡同一时刻的电流可以突变。播放采用精确指数步进，单帧推进上限0.1 s，慢设备可能比墙钟慢。离开可见页面会暂停，返回后需要手动播放，不追赶隐藏期间时间。

能量账本累计实际电源功、当前电场储能和电阻耗散，满足 W源=½CU²+W热。正极板电荷Q=CU，图中正负符号深浅只是示意。没有导电电流穿过电容介质。模型忽略漏电、寄生电阻与电感；开路保持电压不变是理想假设，真实电容会漏电。历史入口为1745—1746年莱顿瓶，说明多位研究者的探索，列Britannica参考入口；不是历史仪器复刻。

## 记录与可访问性

两页均保存当前页面最近两组记录，第三组替换最早一组，刷新清除。CSV含模型版本和SI单位。恢复重新计算仪表，并清除任务完成状态；电容恢复时暂停，仅从保存时刻当前点重新绘图，不补造旧曲线，实际累计能量随快照恢复。对照提示列出变化条件；电容额外比较时刻与挡位，提醒确认此前切挡和初态相同。

主要按钮至少44 px高，参数使用原生滑块，可Tab聚焦、方向键调节。390 px手机布局无横向溢出。无JavaScript时禁用操作按钮，保留数值例子、历史背景、公式和模型说明。历史阅读可折叠，非操作前置条件。
