# 六实验教学体验改进：需求、设计与接口

## 用户反馈与验收目标

新增实验操作难、缺少标准演示、公式与动画的关系不直观。此次参照单摆的教学深度，提供标准过程、即时观察与数据解释，保持每个实验自身布局。

数学先看演示再拼图/剖切；宇宙在轨迹之外增加定量分析与控制变量；桥梁提供明确搭建路线和受力查看；齿轮以装置/控件/关系证据并排呈现。所有内容显式启动，手机、键盘和静态阅读可用。

## 设计

沿用明亮科学馆配色和字体，数据采用各主题强调色。每页首屏含“先看标准演示”与三步观察路线。装置下方证据区包含可读公式、当前数值代入和轻量 SVG 图/HTML 比较条。公式不只是贴在底部，参数改变和模拟步进都重算。

- 面积：保留两棋盘，简化行动在前、精细操作折叠；全等三角形做刚性平移/旋转，逐块提示，面积条相同比例。
- 截面：方向预设先于角度；演示水平正方形→中心六边形→近角三角形；显示真实面积、周长和边长列表。
- 轨道：圆与椭圆演示，实时向量，半径历史，正负能量比较；公式用当前 r、v。轨道要素是点质量二体理想轨道，穿地椭圆单独提醒。
- 三体：八字、初态分离、质量影响三种观察；第一颗星质量/初速度倍率可控，固定步长不变；分离图与能量误差分别解释。
- 桥梁：裸框→一根斜撑→两根斜撑→渐进加载；杆件选择不删，受力值可读，显式删除；反力比例条与杆力表。
- 齿轮：装置和控制并排，速度/扭矩条、累计转数和公式在下方；标准 20:60 减速和中间轮转向对照。

## 接口

没有网络 API。

- `demonstration.ts`: `sequence(update, duration)` 返回 start/pause/cancel/isRunning。进度由 requestAnimationFrame 驱动；暂停保留进度；隐藏标签/pagehide 暂停。参数改变 cancel；减少动态时离散阶段，普通模式平滑插值。
- `evidence.ts`: `bars(id, items, max?, unit?)` 为命名数值绘制等比例条；`history(id, samples, labels)` 用 SVG 展示有标签时间序列，样本最多 500 点。图形不依赖颜色单独传意。
- `ui.ts clock`: 新增 start() 和 onPause 回调；程序演示启动同一时钟，不另开积分循环。
- `measurements.ts`: `polygonMeasurements(points)` 返回 area/perimeter/edges；`orbitalElements(state)` 返回 energy/kinetic/potential/eccentricity/periapsis/apoapsis/period/gravity；`bodyEnergies(bodies)` 返回与软化引力一致的动能和势能。
- 三体 `threeAccelerations(bodies)` 导出与积分相同的软化引力加速度，用于方向箭头；质量修改后两套初态共同重置，仅位置扰动不同。

## 生命周期与模型边界

不自动运行；演示暂停后数值与装置同步冻结。重置、手动操作结束原演示，不能遗留异步参数变化。轨道/三体快放通过更多固定子步推进，图表按模拟时间记录。桥梁的渐进加载是真实重新求解，没有可解结构时不画假位移。位移放大不影响计算。三体近遇及能量误差保护保留，图表明确无量纲；轨道能量为单位质量能量；齿轮扭矩按输入 1 N·m 的理想值示意。
