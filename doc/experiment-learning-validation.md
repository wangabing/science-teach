# 六实验教学体验验收

日期：2026-10-14。对应 OpenSpec 变更：`improve-experiment-learning`。

## 实现范围

六个实验增加显式标准演示与过程说明、当前模型数值代入、实时比较条/图表。数学增加逐步辅助；轨道/三体增加定量观察；桥梁明确搭建、选杆与拆杆；齿轮优化装置与控制布局。

## 模型与构建

- `npm test`：28 项通过。新增截面面积/周长、圆与椭圆轨道要素、静止/径向发射无 NaN、不同质量引力与势能梯度一致、动量守恒检查。
- `npm run build`：44 个文件类型检查 0 错误、0 警告、0 提示，15 页静态构建成功。原有 Three.js 场景仍有大于 500 kB 的打包提示，六个 SVG 实验未引入 Three.js。
- 修正快放下单步语义：卫星始终单步 15 秒，三体始终单步 0.01；快放保持固定积分子步。
- 径向束缚轨道使用半长轴求远地点，避免零角动量情况下 0/0；穿地轨道明确提示。
- 杆件伸缩公式明确包含米转毫米的 ×1000。

## 浏览器验收

本机 Chrome，生产预览 `http://127.0.0.1:4326/`。以下命令可单独运行，`npm run test:browser` 串联全部脚本：

- `scripts/site-browser-check.mjs`：导航、目录、320/390px、键盘、减少动态、无脚本内容。
- `npm run test:browser:buoyancy`：浮力参数、动画、重置、相机、降级与手机回归。
- `npm run test:browser:pendulum`：拖拽、能量、周期、任务、重力/阻尼、动态降级回归。
- `npm run test:browser:exploration`：拼图拖拽/键盘/触屏、截面预设、轨道坠落/逃逸、三体数值保护、桁架平衡、齿轮挑战；六页 320/390px、减少动态与无脚本内容。
- `npm run test:browser:learning`：标准演示完成、暂停/继续、重置/手动接管、后台冻结；数学自动放块/截面度量；轨道圆/椭圆一圈停止和历史清理；三体质量/初速度/方向箭头/差异曲线；桥梁分步与选杆不删、显式拆除、80 kN 对称反力；齿轮输入三圈/输出一圈、转向和扭矩比；320/390px、减少动态、浏览器脚本错误。

新增演示检查使用 Playwright 可控时钟推进 requestAnimationFrame，仍执行页面内实际模型、渲染与事件处理。截图输出在 `test-results/exploration/` 和 `test-results/learning/`，已人工查看齿轮桌面与数学窄屏的装置、控制、公式/证据区域。

验收期间一次构建替换 dist 干扰了预览读取，出现元素等待超时；构建完成后重新执行六实验回归通过。以后先构建，再运行浏览器脚本，避免同时替换被测产物。

## 边界

没有新增后台接口或登录；历史仅在当前实验内存保存，最多 500 样本。轨道参数是二体理想结果，三体软化引力及数值保护保留，桥梁为小变形理想桁架，齿轮扭矩是输入 1 N·m 的理想参考。没有开展真实设备性能基准；手机通过响应式浏览器与触屏模拟验收。
