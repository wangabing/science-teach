# 重心与稳定：设计

## 内容与视觉
题目“稳住这件展品”，主场景旁放重力线落点尺，夹持/释放状态直接可见。亮白馆内背景、淡蓝 #edf5fa 工作台、蓝色 #297cbd 配重、金黄 #edb832 重心、橙色 #ce721e 支撑边界、深蓝 #183b53 文字。Noto Sans SC 讲解、IBM Plex Mono 数据。记忆点是金色重心到台面的竖直线，以及越界后真正绕边缘转动。

首版画面审阅发现配重接近整体重心时遮住 G，已用可见标记与分开的文字避免误读；支撑边界与配重具有不同颜色。装置与落点尺并排，手机上下排列。操作台保留参数、释放与演示，解释/挑战位于下方，避免在画面中叠满控件。

## 科学模型
架按均匀矩形刚体近似：质量 M=2 kg、高 h=1.2 m，支撑宽 b=0.3–1 m、深 0.5 m。固定点配重 m=0.5–5 kg；高度 y=0.12–1.08 m，横向 x 在架内留出可见配重半宽 0.06 m。正倾角 θ 表示向右下降，范围 −60°–60°，g=9.81 m/s²。

整体重心 xG=m·x/(M+m)，yG=(M·h/2+m·y)/(M+m)。台面坐标中重力线落点 q=xG+yG tanθ，原支撑区间 [−b/2,b/2]，稳定余量 d=b/2−|q|。d>0 稳定，d≈0 临界，d<0 失稳，分类容差 10⁻⁹ m。左右临界倾角的绝对值分别是 atan((b/2+xG)/yG) 与 atan((b/2−xG)/yG)。

最近边缘恢复力矩 τ=(M+m)g cosθ·d；正为恢复方向，负为翻倒方向。这是原姿态的判据，不展示负支持力或在接触变化后伪造原支撑面静力平衡。

释放失稳姿态时固定越过的边缘 e，令 φ 是相对台面的顺时针转角：

```
I = M[(b²+h²)/12 + e² + (h/2)²] + m[(x−e)²+y²]
φ̈ = (M+m)g[(xG−e)cos(θ+φ)+yG sin(θ+φ)] / I
```

使用 velocity Verlet，子步不大于 1/480 s；动画帧时间最大 0.05 s。φ 达 ±90° 时架侧面首次接触台面，插值首次接触时间，停止展示且令显示角速度归零。该停止不代表物理碰撞守恒，接触前以重力势能与转动动能核验守恒。同比放大两质量时 I 与重力矩同比增加，运动时间与临界角不变。

释放前静态公式在下方保留，释放后独立显示时间、转角、角速度。三维重心/重力线随姿态变化，原支撑面保留作参考；落地后需要新的接触模型，不把原支撑范围解释成落地后范围。

## 交互与状态
夹持保持初始姿态，即使预览失稳也不自动落下。按松开后才检验；稳定或理想临界不人为翻倒。参数改变取消演示/释放并扶正重新夹持，保留用户设定。演示、翻倒与各自暂停用一个互斥状态机管理，不叠加动画。标准演示一为逐步倾斜并自动释放，二只降低居中配重，固定倾角/质量/宽度。

视图切换、相机操作不修改参数，不终止观察；WebGL 失败/丢失使用同状态 SVG。离页暂停并释放场景，缓存返回重新建立。减少动态下演示四阶段，释放直接显示模型算出的首次接触状态。SVG 静态初始图在 Astro 中也用纯模型生成。

## 架构与边界
复用 Astro 静态页、Three.js 按需场景，不新增引擎。解析模型在 `src/lib/exploration/balance.ts`；场景只呈现坐标，DOM 控制器是参数与动画状态的唯一入口。三维与二维长度同为模型米，二维等比例投影。

只沿左右方向倾斜，固定支点不滑动，不求摩擦系数、碰撞反弹、形变或任意堆积。真实物体可能先滑动，实体活动要有防滑限位。视觉外框、底板和配重外形是示意，惯量采用明确的均匀刚体加点配重假设。
