# 140项实验质量复核与修复

> 2026-10-18更正：本记录是技术检查证据，不能视为140项教学体验合格。潮汐实际试用暴露了静态主图和三维仅相机操作的漏检。后续以[四层验收方案](experiment-experience-acceptance-plan.md)及[全站风险台账](experiment-experience-risk-audit.md)分别记录技术巡检、实际任务与教学复核。

2026-10-17。起因是“皮带传动”实际体验不合格。上一版验收过度依赖页面覆盖、模型求解和自动测试数量，遗漏了历史情境不足、装置静态化、空间表达变弱等学生直接遇到的问题。[上一版交付记录](eighty-experiments-delivery.md)已增加质量更正说明。

本次范围为全部140项：最早20项、此前40项和最新80项。核查对象是实际页面、真实控件、共享计算状态、装置几何和保存的观察证据；不能只检查“页面有一个按钮、有一个canvas”。

## 已发现并修复的问题

| 问题 | 修复后的行为 | 验证依据 |
| --- | --- | --- |
| 皮带只有轮廓，转速没有带来真实运动 | 闭合带面、带宽、轮体、轴和支架；轮辐与带上标记随时间运动；无滑动速比、扭矩、功率和累计圈数同源更新 | 闭合与切线约束、轮缘线速度、功率守恒、浏览器拖轮与播放 |
| 历史内容只是原理，且埋在操作台后面 | 新80项逐项重写人物、年代、问题与应用情境；历史和“看装置/动手操作”入口前置；原理、背景与模型边界分开 | 140页历史展开、来源与页面顺序检查 |
| 进入装置后找不到可操作的位置 | 120个共用工作台在装置旁提供主变量滑块，与完整控制区双向同步；保留情景、单变量对照、记录与撤销 | 实际键盘操作、逐控制最小/最大值和动态范围检查 |
| 控件值与实际计算条件不一致 | 修正相对论载荷质量、干涉仪波长的默认值/步长；连续时钟不再被原生range偷偷取整，手动方向键仍遵守声明步长 | 全120模型默认值步长合法性、逐量比对UI和空间测量 |
| 部分动力实验只有静态示意 | 补充阿特伍德释放、弹簧能量释放、圆周运动、驻波、多普勒发射、带传动、行星轮、四杆、螺旋举升和引力钟等状态联动；说明慢放比例或构造扫描的含义 | 物理关系单测、时间单步与实际几何变化 |
| 图形与受力或位置脱节 | 修正桁架高跨比、梁反力、柱端约束与失稳提示、偏心应力、斜面接触、楔块推进与举升；四杆、剪叉使用一致长度比例 | 机构全角域杆长不变、控制响应与图像审阅 |
| 空间视图丢部件或遮挡证据 | 文丘里管采用圆形渐变通道；变压器为绕铁芯的空间线圈；弹簧为螺旋线；蜂窝壁为有厚度的实体；致密星/火箭用透明剖视保留内部比较 | 2D/3D截图、实时读数和模型边界 |
| 平面字幕被错放到手工空间模型 | 只在使用同一图面坐标的空间构造中继承字幕；折叠、曲面等手工模型保留自己的坐标和标识 | 原40项空间截图复查 |
| 光帆切换研究模式崩溃 | 随模式重建测量项、主读数与记录摘要；CSV保留各模式出现过的全部观测量；旧记录补齐新增默认字段 | 模式切换浏览器检查、混合模式CSV测试 |

## 验收范围与证据

逐项结果和图片索引见[140项核查台账](experiment-quality-audit.md)。皮带传动可直接查看[二维实拍](assets/quality/belt-drive-2d.png)和[三维实拍](assets/quality/belt-drive-3d.png)。图集位于[质量证据目录](assets/quality/)，每张图注明实验编号；逐项数据保存在该目录的JSON台账中。

共用工作台逐控件检查包括：真实键盘或选择操作、有效上下界、控件回显、模型指标、页面读数、三维测量和状态边界。对于时间模型，检查单步、播放、暂停及几何变化。最早20项的深入接线、拖动、测量、预测任务、存储恢复和回退由原有专用回归覆盖。

桌面截图按默认条件取二维证据，三维时间实验会在单步/播放后取证；手机截图在改变主变量后取证。因此两张图的数值不一定相同，不能把它们误当作同一时刻的截图对照；同状态一致性通过实际逐量断言核验。

### 验证记录

- 科学模型与证据逻辑：280项通过。
- 全站逐项质量检查：141项通过（140条路由＋皮带直接拖动专项）；120个共用工作台覆盖366个控件、732次上下界探测。
- 桌面二维、三维及手机截图：420张，已逐组审阅；完整原图保存在本地被Git忽略的 `test-results/quality-evidence/`，精简图集与逐项JSON随文档保留。
- 情景任务及旧功能回归：原有330条Playwright测试和10组Node浏览器流程通过；其中最终完整情景回归137项通过，七组早期实验流程复测通过。最后两处UI修复后，另有五项失败场景专项和八项逐页质量检查通过。
- 最终生产构建：155个Astro文件检查无错误、无警告、无提示，生成147页。打包器仍提示部分脚本块大于500kB，这属于后续性能优化事项。
- 历史来源：111个去重链接中87个返回200；24个访问受限或未获得确定响应，均在[来源台账](assets/quality/sources.json)保留状态。已发现的404、同名误引和返回200的假404已修复。HTTP200本身不等于逐篇学术内容审校。

逐项全站检查后，旧场景回归继续发现了三处取景不足和两处手机悬浮遮挡；修复后五项专项通过，并完成137项完整场景回归。最后两项UI修复不改变模型、历史或原生实验，完整140项取证与受影响项复测的构建范围在验证记录中分别注明。

OpenSpec质量要求已同步，10项任务完成并归档；归档前29项、归档后28项严格校验均通过。

机器可读汇总见[验证记录](assets/quality/validation.json)。

## 质量判断的边界

数学平面构造、电路图、场与波形的空间展示仍是解释视图，不因为可以旋转就成为新的物理实验。静力、稳态交流、几何约束等页面不会伪造运动来增加热闹程度；相关边界在各页明确说明。力箭长、星体尺度、工程变形与部分位移有可读性放大，量值以仪表和已声明模型为准。

本轮验证使用桌面Chrome及320/390px视口模拟，未进行真实学生课堂复测、北京教师教学评审、所有手机GPU或跨浏览器实机认证。图集审阅与关系测试能够发现和防止本文列出的具体问题，不能被表述为“所有作品已经获得世界顶级教学效果认证”。访问受限的博物馆、百科与期刊链接在来源台账中单列，不将403或网络超时误报为正文已核实。
