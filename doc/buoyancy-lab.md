# 三维浮力实验 Demo

## 打开页面

运行 `npm run dev`，访问 `http://localhost:4321/stem-lab/buoyancy/`。此页面使用独立样式，通过导航返回科学探索首页。静态构建后可直接部署；无需 API 密钥。

## 操作

- 拖动实验台旋转，滚轮或双指缩放；聚焦实验台后用方向键调整视角。
- 调整浸入深度（相对当前液面，0–10 cm）与液体密度。
- 播放一次完整入水过程，可暂停；手动操作自动结束演示。
- 点击三个关键状态阅读即时推导；重置恢复水、5 cm 浸入和初始视角。
- 蓝、橙、绿箭头分别表示浮力、重力、拉力，长度采用同一比例。

## 模型

10 cm 铝立方体，ρ物=2700 kg/m³，g=10 N/kg，G=27 N。方形容器内底面积 400 cm²，初始水深 15 cm，物体保持悬挂且不触底。

V排=100h浸（cm³）；F浮=ρ液gV排（体积换算为 m³）；T=G−F浮；Δh=V排/400（cm）；p=ρ液g(15+Δh)/100（Pa，仅液体贡献）。三维液面、物体位置、力箭头与数值读数来自同一个计算函数。

这是准静态教学模型，忽略空气浮力、粘性、浪涌和绳子体积，不模拟测力计弹簧动力学或真实折射。完全浸没后的继续下沉不在控制范围内。WebGL2 不可用时显示固定示意图，但计算与控件仍可使用；固定示意图不随深度改变。

## Anatomy 与 Three.js

参考 [Anatomy](https://github.com/wheresryan22/anatomy) 的真实装置、共享模型和可操作原理图方法。使用 Three.js 自行构造仪器和交互，没有安装或复制 Anatomy 的 beta 三维运行时。Three.js 由实验页面独立加载，科学探索首页不会加载三维运行时。

## 验证

- `npm test`：包含浮力模型边界、受力平衡、密度变化与无效值测试。
- `npm run build`：Astro 类型检查和静态构建。
- 开发服务器启动后，`npm run test:browser:buoyancy`：无头 Chrome 检查读数、演示、重置、视角、320/390px、减少动态偏好、无 WebGL 与科学探索首页。
- 截图位于 `test-results/buoyancy/`。

## 首次观察与装置边界

保持液体不变，只拖浸入深度，观察浸没部分对应的排水体积。控制旁有体积示意与代入式。滑块范围0–10 cm，当前只能到刚好完全浸没，不能继续下沉；完全浸没后深度改变而浮力不变，是理想模型推论，不是本装置已完成的操作证据。水槽底压强不能当作物体下表面的压力。
