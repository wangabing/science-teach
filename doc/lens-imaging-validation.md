- `npm test`：33 项模型测试通过，其中新增五项测试覆盖五成像情景、两代表光线交点/焦点平行、独立光屏调焦、虚像不能投屏、近焦正负远像、单位缩放和非法输入。
- `npm run build`：51 文件类型检查 0 错误、0 警告、0 提示；静态构建生成 16 页。
- 原 Three.js 场景保留超过 500 kB 的打包提示；新透镜页使用 SVG，首页不加载完整场景。
- 理论像与实际到达光屏的光路分别表达；像超出视野/行程明确提示，不将近焦 Infinity/NaN 写入 SVG。

## 实际边界

薄透镜、近轴近似；光屏分离量是代表光线几何指示，不是实际光学分辨率。预览未模拟亮度、像差和衍射。浏览器响应式/触屏模拟通过，不等于真实移动设备性能基准或青少年教学效果评估；后续可按路线安排目标年龄体验者试用。
