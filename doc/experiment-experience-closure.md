# 全量体验巡检问题修复记录

原始140项筛查报告保持不变。本表逐条对应原来的60条候选线索、49个实验。真实学生试用和教师复核转至推广后反馈，本轮以产品操作、独立科学关系和浏览器巡检验收。

## 修复方式

- 对确实错误的装置表达修正世界线、面积/力箭头、温度颜色、保温层和播放速度。
- 对合理的固定形状，补充受力、能量、频谱、尺度等可见测量证据，并解释不变量。测量证据单独分类，不冒充真实形变或主装置几何变化。
- 比较默认态、过程态，以及摩擦/吸收所需条件；不以文字变化证明画面响应。
- 静态工作台增加具名参数扫描，明确不是物理时间；暂停、单步、减少动态、撤销和重置保留。
- 回归额外发现并修复C10色块数千独立网格造成的三维初始化迟缓，以及手机下拉控件被观察窗遮挡、潮汐标记线截获拖动。另限制三维测量标签列宽，避免长单位重叠。首次失败及增量复测记录保留在报告中。
