# 月相与日月食：设计

## 呈现与记忆点
“双视角观测站”：宽日地月工作区旁放地球天空。月盘是大幅真实纹理球面，下面的太阳盘用相同日月角大小比例展示遮挡。深蓝 #091b30 仪器视窗置于明亮 #f3f8fc 科学馆页面，地球蓝 #348ad0、月面灰 #c6d0dc、太阳金 #ffc86b、红月 #ad563e；Noto Sans SC 讲解，IBM Plex Mono 数据。手机上下排列，两视图具有明确标题。

实验不是连续自动运转的宇宙装饰。初次进入保持静止，观众动月球时，普通明暗分界、黄纬、受光比例和日月食证据同步改变。额外的阴影截面将本影、半影与月盘按同一真实比例展示，避免通过全景压缩几何判断食的范围。

## 科学模型
距离以地球半径 R⊕ 为单位：地球半径 1、月球 0.2727、太阳 109.1、平均日地距离 23455、地月距离 56–64。θ 为轨道位置、Ω 为交点方向、i 为倾角（默认 5.145°），u=θ−Ω：

```
x = d(cosΩ cosu − sinΩ sinu cosi)
y = d sinu sini
z = −d(sinΩ cosu + cosΩ sinu cosi)
```

太阳在 +x，黄道北为 +y。正轨道进度让上弦亮右、下弦亮左。对相反向量的夹角用 atan2(|a×b|,a·b)，避免小角度 acos 精度损失。黄纬 β=asin(y/d)。地心月盘的局部基底为右向量 (Earth→Moon)×North，向上向量 (Moon→Earth)×Right；不包含地平线旋转或天平动。

相位角 α 为月球指向太阳与地球的夹角，k=(1+cosα)/2。它是未扣除月食遮光的月相受光比例；月全食时 k 仍接近 1，但实际月面被遮光。月面纹理固定显示近侧，无天平动。

日食测点固定在 (1,0,0)：朝日侧的理想赤道点，不是指定城市。太阳/月球的角半径 ρ=asin(R/d)，其中心角距由观测点向量夹角计算。均匀亮度太阳盘与月盘的小角度平面圆重叠面积 / 太阳盘面积给出遮挡比例；全遮挡为全食，月盘完全处于较大太阳盘内部为环食，否则为偏食；月球在太阳后方或背日方向不遮挡。观测点在地表，包含该点到月球的距离变化；月盘另外采用地心视角。

月球背日侧轴向距离 s=−x、离轴距离 b=√(y²+z²)，阴影圆锥截面为：

```
r本影 = 1 − s(109.1−1)/23455
r半影 = 1 + s(109.1+1)/23455
```

月盘和阴影截面按均匀投影圆重叠估计覆盖：完全入本影、部分入本影、只入半影、无食分别显示全/偏/半影/无食。近食时月球几乎垂直影轴，此近似足够教学，不作为精确接触时刻计算。三维与月盘像素在每个表面采样点计算太阳被另一球体挡住的角面积，因而日食阴影在地球表面、地影在月球表面，不使用压缩装置的 shadow map。

月面主光遵循球面 Lambert 光照，少量暗面亮度为地照的示意。月食直接光随真实遮挡降低；额外红光为大气透射的颜色近似。地球大气边缘与太阳日冕亦为视觉示意，未模拟完整散射、折射、临边昏暗或辐射强度。

## 架构与性能
纯模型在 `src/lib/exploration/moon.ts`，DOM 控制器是参数与演示状态的唯一入口。Three.js 场景按需导入，自定义材质用真实物理坐标计算光照和遮挡；装置地月距离压缩，月球放大以便拖动。星空为固定伪随机分布，未自动运动。纹理从本地加载，来自 NASA SVS LROC / Blue Marble，署名见 [素材清单](../public/textures/astronomy/CREDITS.md)。

地心月盘为 224×224 Canvas，预缓存球面采样、纹理坐标，用同一物理遮挡函数绘制。天空画面不是静态月相图片切换。普通无月食状态跳过逐像素遮挡计算，演示约 22 fps 更新，静止时无持续渲染。Three.js 对加载晚到的纹理和离页对象释放资源。

## 状态与边界
两段演示分别为 18 秒一轮月相、12 秒保持满月只改变交点。状态 idle/cycle/nodes 与 paused 互斥；参数变化停止演示，视图变化保留状态，后台暂停，bfcache 返回重建三维且不自动继续。减少动态分四段呈现。

WebGL 初始化失败或丢失切回同状态 SVG。月面纹理失败改用有明确说明的球面光照示意；天空 Canvas 不依赖 WebGL。无脚本保留纹理参考、轨道图和实体活动。平均朔望月 29.53059 天只表示教学进度；没有真实日期、自转、偏心轨道、地平线、章动或精确食季预报。
