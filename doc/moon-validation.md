# 月相与日月食：验收记录

日期：2026-10-16。环境：Node.js 24、Astro 7、TypeScript、Three.js、本机 Chrome，生产构建预览 `http://127.0.0.1:4326/`。OpenSpec 变更 `add-moon-phases-and-eclipses`。

## 模型与构建
- `npm test`：52 项通过，其中新增 7 项天文测试覆盖四个关键月相、亮面方向/北向上、真实角大小、轨道距离/交点/拖动逆映射、圆重叠独立解/对称/相切、距离导致全食/环食、偏食、全/偏/半影/无月食、有限光源遮挡和输入边界。
- `npm run build`：70 个文件检查，零错误、警告和提示；19 个静态页面成功生成。构建保留原有 Three.js 分块超过 500 kB 的 Vite 提示，三维代码按页面加载，首页不加载 Three.js。
- `openspec validate add-moon-phases-and-eclipses --strict`：通过。

## 专属浏览器验收
`BROWSER_CHECK_URL=http://127.0.0.1:4326 npm run test:browser:moon` 已通过：
- 实际 Canvas 像素检验上弦亮右/下弦亮左、满月与暗红月全食、日全食遮黑与环食亮环；不只核对标签。
- 满月远离交点无食、接近交点全食，以及指定地表观测点全/偏/环食。
- 二维真实拖动/键盘、三维射线命中真实拖动与键盘相机、视图切换保留参数/证据。
- 两段演示完成、暂停/继续、手动接管、预测反馈、真实倾角挑战，防止把倾角压到零绕过任务。
- 后台暂停、离页资源释放、缓存返回不自动继续，实际 WebGL 上下文丢失、无 WebGL、纹理网络失败后的可操作示意。
- 320/390 px 无横向溢出、触屏微调、减少动态分阶段演示、无脚本静态图与实体活动、宇宙空间三个实验及探索路线。

画面审阅包含桌面观测站、满月、日全食、日环食、红色月全食、二维轨道、390/320 px 页面。截图在 `test-results/moon/`，包括 `moon-views.png`、`moon-desktop.png`、`moon-full.png`、`moon-solar.png`、`moon-annular.png`、`moon-lunar.png`、`moon-2d.png`、`moon-390.png`、`moon-320.png`。

首次画面验证发现 GLSL include 语法不完整，已修复并由浏览器控制台无错误验收覆盖；俯视相机朝向与取景也已调整。验收通过的是修正后的实现。

## 科学与验证边界
月相几何比例不是照片平均亮度；月全食未扣除遮光的 k 仍约 1。太阳盘采用均匀亮度小角度圆重叠、月食采用圆锥截面圆盘近似；红月、大气边缘及日冕为视觉近似。指定日食观测点不是任意城市，更不代表全球可见。压缩装置的几何不参与食计算。

没有真实日期历书、自转/天平动、完整散射/折射或接触时刻预报；没有青少年真实参与者试用或低端真机性能测量。自动化正确性不代表已证实教学效果。NASA 纹理已本地保存并署名；本轮没有新增运行时依赖，没有提交或部署。
