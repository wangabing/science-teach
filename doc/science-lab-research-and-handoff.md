# 青少年科学探索网站：设计调研与新仓库交接

整理日期：2026-10-14。

本文可单独复制到新仓库，供后续开发者或 AI 助手读取。它记录用户目标、设计建议、参考项目及已有实验的迁移线索，不依赖之前的对话。文中的建议尚未全部经用户确认，不应当作已经批准的实现规格。

## 1. 用户目标与当前阶段

用户已经体验并认可现有的三维浮力实验和单摆实验，希望以此发展一个适合青少年科普学习的网站。

用户明确提出的方向：

- 科技感十足、阳光向上，适合青少年；避免阴暗、神秘、玄学式视觉。
- 首页由一块块“空间”构成，每块是一个大的实验分类。
- 候选空间包括物理实验室、三体科技实验室、数学几何实验室、三维实验室。
- 空间可以补充，但总数保持有限；长期重点是丰富空间内的实验。
- 每个实验至少有一个独立页面，重视操作细节、互动体验与原理讲解。
- 希望参考 GitHub 上适合的设计与可体验演示。

用户最新行动：准备新建仓库，在新仓库继续本项目；本轮只要求整理交接文档，尚未要求创建新站或迁移代码。

## 2. 仓库与产品定位结论

建议采用独立仓库、独立品牌与独立部署，复用已经完成的实验成果。

现有项目 `rebirth-english` 的产品是“想你的365夜”，面向成年中文母语英语学习者，核心是夜间阅读、朗读和口语排练。新站面向青少年、家长与教师，核心是科学探索与动手实验。

| 维度 | 想你的365夜 | 新科学探索网站 |
|---|---|---|
| 用户 | 成年英语学习者 | 青少年、家长、教师 |
| 场景 | 阅读、朗读、表达练习 | 预测、实验、观察、理解 |
| 气质 | 安静、文学、陪伴感 | 明亮、好奇、精密、有活力 |
| 内容结构 | 每夜文章、学习路线 | 实验空间、科学问题、关联知识 |
| 长期能力 | 声音与语言学习 | 模拟、测量、实验工具与互动课程 |

技术上可以继续放在一个项目里，但随着首页、导航和产品能力扩展，独立开发更清晰。无需复制整个英语站，也无需重写已验证的实验。

迁移建议：

1. 在新仓库建立科普站的基础结构与品牌。
2. 迁移浮力和单摆的页面、模型、场景、样式、测试与文档。
3. 替换原页面中的“返回重生英语”、页脚链接及站点身份信息。
4. 新站稳定后，再决定旧实验地址采用迁移提示、跳转还是继续保留。
5. 初期不建立复杂的跨仓库共享包；等多个实验出现稳定共性，再抽取工具。

## 3. 推荐的空间结构

首期建议四个空间。以下是设计建议，命名尚待用户确认。

| 空间 | 内容方向 | 首页代表装置 | 首期内容建议 |
|---|---|---|---|
| 物理实验室 | 力学、光学、电磁、波动、热学 | 摆球、棱镜或磁场线 | 迁移浮力与单摆 |
| 数学与几何实验室 | 数形结合、函数、概率、几何变换 | 可展开的多面体 | 一个几何互动实验 |
| 宇宙与三体实验室 | 引力、轨道、三体问题、混沌与尺度 | 三颗恒星的运动轨迹 | 一个三体引力实验 |
| 空间与建造实验室 | 结构、机械、投影、空间想象 | 齿轮、桁架或剖切模型 | 后续补充真实可用实验 |

分类调整的理由：

- “三维”是多个实验都会采用的表现方式，与物理、数学等知识分类并列时容易重叠。建议把“三维实验室”改为有明确主题的“空间与建造实验室”。
- “三体”适合作为宇宙空间里的特色专题。这样保留小说带来的吸引力，也能扩展到真实天文学、航天和引力。
- 一个实验设置一个主要归属，通过“能量、混沌、对称、空间”等标签建立跨空间关联，避免重复维护。
- 首页展示的实验数量必须来自真实内容；未开放的空间应明确显示状态，不用虚构实验填满界面。

长期以增加实验内容为主，谨慎增加顶层空间。

## 4. 首页设计方向

推荐方向：**阳光下的未来科学馆 / 明亮的交互科学馆**。

科技感来自可以操作的科学现象、精密仪器、清晰图形和有依据的数据。主站避免大面积黑底、霓虹、神秘符号与无意义的装饰动画。

### 色彩与材质

- 偏白底色与天空蓝构成明亮环境。
- 阳光黄用于重点入口、探索提示或仪器细节。
- 青绿色用于运动轨迹、动态图形或数据。
- 深蓝文字保证对比与阅读质量。
- 金属、玻璃、透明亚克力等仪器材质提供精密感。

以上是方向，尚未确定品牌色值、字体、标志和最终名称。

首页和导航保持统一；实验内部可根据主题选择环境。例如光学实验可以采用有科学用途的暗背景，单摆现有深靛蓝仪器风格也不必立即推倒重做。

### 首页信息结构

```text
品牌                         探索空间 / 全部实验 / 关于

一个可以亲手改变的科学现象
一句引导问题                         [开始探索]

┌─────────────────┬─────────────────┐
│ 物理实验室       │ 数学与几何实验室 │
│ 代表装置 + 问题  │ 代表装置 + 问题  │
├─────────────────┼─────────────────┤
│ 宇宙与三体实验室 │ 空间与建造实验室 │
│ 代表装置 + 问题  │ 代表装置 + 问题  │
└─────────────────┴─────────────────┘

今天试着回答：为什么更重的摆球没有摆得更快？
精选实验 / 最近新增

科学模型说明 / 内容来源 / 关于项目
```

具体建议：

1. 首屏用一个可玩的科学现象引起好奇，例如拖动小球改变轨道，并提出“如果初始位置只差一点，未来会差多少？”。具体首屏现象待选。
2. 四块空间做成宽幅展台，每块包含代表装置、一个科学问题、真实实验数量和进入入口。装置占主导，文字有留白。
3. 交互表达主题，例如几何体展开、光束穿过棱镜。手机点击要有对应操作，不能只依赖鼠标悬停。
4. 各空间有自己的强调色，结构、字体与控件保持一致。
5. 首页负责引起好奇与选择方向，空间页负责实验目录，实验页负责深入探索。
6. 不同时启动四套完整三维场景。首页建议一个轻量交互，其余空间使用高质量预览，进入实验再加载完整场景。

## 6. 每个实验共同的学习节奏

**预测 → 操作 → 观察 → 解释 → 再挑战**。

- 开始前提出一个具体问题，让学生有目的地操作。
- 默认显示必要参数，深入工具逐步展开。
- 数值、装置、图表和公式使用同一个物理或数学模型。
- 讲解随着实验状态变化，避免只在页面底部堆砌公式。
- 通过对照实验和测量支持结论，让学生有可观察的证据。
- 明确说明模型假设、适用条件及忽略因素。
- 保留键盘操作、移动端交互、减少动态和渲染失败后的可用路径。

已有单摆实验中的预测反馈、参考摆、实时能量图、实测周期、慢动作与单步可以作为后续实验的设计样本，但不要求每个实验复制相同工具。

## 7. 三体专题的科学表达

应区分三类内容：

| 内容性质 | 示例 | 呈现方式 |
|---|---|---|
| 已验证科学 | 万有引力、轨道运动、能量关系 | 给出模型、依据与可操作验证 |
| 理想化模拟 | 质点三体、简化轨道与初始条件敏感性 | 明确假设、数值误差与适用范围 |
| 小说设定 | 水滴、智子等 | 明确标注虚构前提，解释它与现实科学的联系及边界 |

真实的三体问题和混沌现象已经有足够强的吸引力，不需要加入玄学解释。小说相关名称、角色或视觉素材的具体使用范围后续单独确定，不能默认拥有官方授权。
