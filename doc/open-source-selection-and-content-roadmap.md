# 科学探索实验室：GitHub 开源项目调研与内容规划报告

调研日期：2026-10-15。状态：产品建议，尚未进入实现。此次不修改网站代码，不安装或部署候选项目。

## 核心结论

建议采用“借鉴实验设计，按需复用计算能力，创作自己的教学体验”的路线。保留现有四个空间和八个实验，以内容质量、可操作性和科学证据为主要投入方向，课程、账号和学习记录继续后置。

推荐三个项目：Ray Optics 用于光学新内容，CindyJS 用于复杂几何互动，Matter.js 用于机械搭建探索。优先完成一个自有风格的透镜成像实验作为内容样板，再逐步扩展数学、建造和宇宙主题。

Ray Optics 是可直接独立使用的完整工具；CindyJS 和 Matter.js 是需要我们另行创作教学内容的框架或引擎。三者都不应仅换皮后作为完整教学产品发布。本站的问题引导、标准演示、公式与实时数据、挑战反馈和视觉设计仍需独立完成。

## 目标与筛选方式

服务现有八个实验、四个空间，以内容创作为主；保留自有视觉、科学问题、演示、操作、实时证据和解释。评估教学适配优先于 Star 数量；随后考虑许可、维护信号、现有 Astro/TypeScript/SVG/Three.js 兼容性和部署成本。

实际使用 GitHub Search API 搜索 ray optics、interactive geometry、physics simulation educational、solar system simulation，并读取已知候选仓库元数据。使用 GitHub Contents API/原始文件核实前三项目的 README、许可证及可取得的构建配置。未实际安装、构建、审计全量源码或完整体验在线演示；以下部署难度为文档评估。

日期取 GitHub `pushed_at`，是最近推送，不等于最新功能提交或正式版本发布时间；Star 是查询当时快照。

### Ray Optics

可直接使用完整在线模拟器或按说明构建独立自托管工具。README 确认光源、镜面反射、折射、理想透镜、色散、虚像、测量、案例图库及 Node 模块能力；浏览器内嵌为自有可控组件的接口仍需验证。

自有风格需要二次开发：隐藏复杂编辑菜单；只开放当前教学目标所需操作；编写问题、默认情景、标准演示、挑战与反馈；将测量值接入本站公式和数据证据；适配键盘、手机及暂停生命周期。建议首个主题“物体跨过焦点，像会怎样变？”；第二主题“光为什么会拐弯？”。

风险：完整 npm build 会生成大量图库图片，README 提示约半小时，并可能需要 node-canvas 系统依赖；Node 模块可用不表示可以无改动接入 Astro 浏览器；WebGPU 为 Beta，不作为首版必要条件；几何光学与波动光学范围须区分。

### CindyJS

可直接使用框架、文档和示例，不是可直接换品牌的教学网站。适合拖动几何、约束构造、轨迹与变换。推荐内容“椭圆为什么能用一根绳画出来？”和“对称变换如何铺满平面？”。

自有风格需要二次开发：CindyScript/JS 状态桥接、触屏与键盘入口、可读测量、证明解释、演示和任务反馈。简单二维作图可继续用现有 SVG，只有约束构造复杂度确实下降才引入框架。莫比乌斯带可按现有 Three.js 创作，不因选型强行放入此框架。

风险：新增脚本语言和构建体系；README 说明部分文档是支持目标，具体功能可能落后于文档；不能默认图库的每个示例和外部素材都只有主仓库许可证。优先固定可验证版本和有限功能。

### Matter.js

引擎及示例可直接运行，提供碰撞、约束、摩擦、复合刚体、拖拽和 Canvas 渲染。适合“搭一条小球机关”“重心越过支撑面会怎样”等搭建探索。

自有风格需要二次开发：场景、操作工具、标准演示、物理量与单位映射、测量/图表、任务判定及数值误差解释。杠杆、滑轮等要求定量结论时，先明确解析关系与约束误差，必要时采用解析模型、引擎仅服务交互展示。

风险：实时刚体求解有数值误差、约束漂移和碰撞近似，不能把视觉效果直接当作精确守恒证明；不能替代现有桥梁刚度求解、轨道积分或三体模型；自由搭建范围若不收敛，内容成本容易扩大。

## 内容路线建议

第一阶段：先完成一个原创风格的“光学实验室”内容样板。用透镜成像贯通预测、拖动物体、观察实/虚像、数据与公式、标准演示和再挑战。把现有“面积→截面”“齿轮→桥梁”“轨道→三体”写成短探索建议，保持自由进入，不做账号和学习记录。

第二阶段：按内容价值逐个扩充。数学优先莫比乌斯带（把单面/单边和剪开后的连通变化讲准确）或椭圆绳子；建造优先小球机关/重心；宇宙优先月相与日月食（从观察位置和阴影解释，明确月相并非地影）。每次完成并验证一个作品，再决定是否扩大为系列。

第三阶段：将验证有效的实验组成跨空间专题，如“守恒”“形状改变什么”“预测的边界”。加入可打印探究任务、生活装置与实体小实验建议；是否需要保存作品/记录，由真实回访需求决定。

共同验收：学生能说出问题、在少量操作后看到变化、从数据解释结果，并完成一个迁移挑战。建议每件作品找 3–5 名目标年龄体验者试用，记录卡住位置、是否需要提示、是否能用证据解释。它是形成性反馈，不是统计有效的教学效果结论。所有新选题及优先级仍属于本次规划建议，未获实现授权。
