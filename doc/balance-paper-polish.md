# 重心与纸带：让证据可以对照，让连接可以验证

日期：2026-10-16。对应 `product-polish-benchmark-review.md` 的优先级 2、3，承接透镜标杆打磨。

## 重心：保留 A，只改高度

在 `/labs/balance/` 先布置一个姿态，例如“高处配重”。点“留作 A，只改高度”，当前释放前条件保留为 A。B 初始与 A 相同；对照区可以直接调整 B 高度，同时看到两把落点尺、稳定余量、向右临界角和恢复力矩。

对照期间固定台面倾角、支撑宽度、架/配重质量和配重横向位置。主装置的其它滑块与倾角微调会锁定；即使使用二维/三维拖动，也只改高度。改变 B 会扶正并重新夹持，静态证据对应释放前条件。台面水平时，改变高度不会改变当时的落点和余量，页面按模型如实解释。

“结束对照”恢复自由操作；选择其它预设、标准演示或运输挑战也会明确结束对照。两组保留在当前页面，不宣称刷新保存。

## 重心：通过之后，再验证理解

运输挑战仍要求 20°、至少 3 cm 稳定余量。通过后出现“如果所有质量都加倍呢？”；先预测向右临界角会变大、不变还是变小，再点“把所有质量加倍，检验”。

独立验证台保留刚通过的几何条件，同时将架与配重质量乘二。两张证据卡显示临界角与余量不变、恢复力矩加倍。解释来自重心公式分子和分母同比缩放，不把“只增加配重”等同于所有质量加倍。主装置不变，修改装置后旧验证失效，需要重新检验挑战。

## 纸带：一点点剪，而不是跳到答案

在 `/labs/mobius/` 先预测条数，再点“沿中线剪开”。红点沿中线推进，已完成的角段显示扩大切缝，未完成的部分保留整宽连接。工作台下的独立“中线剪切进度”可定位 25%、50%、75% 等阶段；手动调整会停止自动剪切。

“暂停剪切 / 继续剪切”用于自动过程。切换后台会暂停，回到页面不会自动续剪。恢复、重置或换纸带会结束旧过程，不会稍后覆盖新状态。减少动态模式不自动剪，由学生主动推动滑块。

未剪完时暂不宣布最终结果；纸面/边界读数明确标为未剪纸带的原始性质。100% 时才验证预测、切换剪后面数和总边界数。

## 纸带：选一条完整的带，走回起点

剪完后工作台提供完整纸带选择：一次半扭转只有第 1 条；零次和两次各有两条。选每条带，分别“沿纸面走”“沿纸边走”或“沿新切边走”。原纸边是外侧边界，新切边是内侧边界，两条路径有独立位置。

剪后的莫比乌斯带需要绕中心两圈返回；普通纸环和双半扭转的每条带一圈返回。选择第 2 条时，标记和路径确实进入第二个连通分量，二维与三维共用参数。拖回剪切进度时会清除分量选择，剪完才能重新追踪。

画面扩大切缝，不模拟剪刀碰撞、纸张弹性或拉伸；投影交叠不等于连接，建议旋转和实体纸条核验。两次半扭转剪后的两条带仍套连。

## 验收与限制

- 模型与逻辑：`npm test` 共 57 项通过；新增部分剪切与每个分量/两种边界接缝闭合检查。原重心质量同比缩放、力矩与惯量检查继续通过。
- 构建：`npm run build` 成功，73 文件检查无错误、警告、提示，19 静态页面生成。Vite 仍提示现有 Three.js 分块超过 500 kB。
- 新增流程：`npm run test:browser:polish` 8 项通过，覆盖高度对照、迁移预测、三种纸带渐进切缝/分量路径、自动暂停、手动接管、后台暂停、320/390px 和减少动态。
- 既有回归：`npm run test:browser:balance`、`npm run test:browser:spatial`、`npm run test:browser:observation` 均通过。
- 浏览器使用本机 Chrome 和构建产物；命令支持 `BROWSER_CHECK_URL`。截图位于 `test-results/polish/`，不纳入版本。

真实学生试用尚未开展。建议 3–5 位目标年龄体验者完成：独立保留 A、只改高度并解释两组落点；预测所有质量加倍后的临界角并用数据解释；在半剪处指出未剪连接；剪后分别追踪每条带并解释为何返回起点才能确定是一条完整的带。记录停顿、求助、误操作与解释，不据自动测试宣称教学效果。

三个代表实验的规划功能已落地。下一轮根据真实试用反馈决定是否把保存/对照/迁移问题推广到月相、桥梁和齿轮；主题路线与方法路线、参数分享和发现卡仍属于后续规划。
