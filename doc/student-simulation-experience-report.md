# 5 名中学生使用 12 个实验的体验报告

日期：2026-10-16  
评估对象：当前工作区的“科学探索实验室”，四个空间、十二个实验。   
交付范围：体验报告与改进方案；未修改产品代码。

## 1. 主要判断

网站已具备很好的“动手发现”基础：具体问题比章节目录更容易激发兴趣，操作与读数联动能支持解释，标准演示让第一次接触有入口。透镜首次调焦、纸带连续剪切、重心固定条件对照尤其值得保留。

下一轮最有价值的工作，是让学生完成“我猜什么 → 我只改什么 → 我看到什么 → 这支持什么解释”，并留下可回看的证据。中，年龄较小的角色需要日常语言和单一目标；有基础的角色需要自主操作、比较与迁移；高年级角色需要定量分析和模型边界。这些需求也受学科经验影响，不能只按年龄分层。

优先处理四件事：

1. 每个实验提供一项明确的首次任务，分开“看演示”和“自己验证”；保留现有优秀入口。
2. 在操作附近解释必要术语和误解，尤其是体积与深度、虚像与光屏、月相与地影、轨迹分离与数值误差。
3. 为长页面提供任务定位与轻量证据记录；手机观察条已有基础，但不能替代看见装置变化。
4. 挑战通过后加入一个解释或迁移问题，判断学生是否会解释，而不仅是否调到了正确参数。

这些是待真实学生验证的产品假设，不是“五名学生证明了产品有效”。

## 2. 方法、证据与边界

### 2.1 如何

先核对实验目录、页面文案、交互实现和已有操作指南；再在本地 Chrome 中逐页打开、操作代表性任务，检查桌面 1440 × 1000 和手机 390 × 844 布局。随后以五种不同知识基础、兴趣和设备情境推演使用过程。

每名角色都覆盖全部十二个实验，共 60 条体验记录。为避免把疲劳当成实验难度，设想分为四次使用，每次一个空间的三个实验；首次探究、解释与后续挑战分开。该安排没有真实计时，不报告完成率、平均耗时、满意度分数或学习提升百分比。

报告中：

- **实查**：浏览器可见、实际操作得到或源代码可直接核对的事实。
- ****：角色可能的行为、疑问、反馈与学习收获，均为分析推演。
- **建议**：尚待验证或实现的设计，不描述为现有功能。

### 2.2 实查结果

| 证据 | 实际核对 | 能说明什么 / 不能说明什么 |
|---|---|---|
| E01 全站入口 | 首页及十二个实验页面均返回 HTTP 200；目录为 12 个实验、4 个空间 | 路由可访问；不等于所有学生都能找到适合自己的起点 |
| E02 透镜 | 首次调焦从“尚未对焦”到屏距 15 cm 的“你调清晰了”；切换放大镜得到正立放大虚像；记录两组后给出固定条件与变化比较 | 首次任务、状态反馈与记录可用；学生是否理解虚像仍须解释题验证 |
| E03 面积 | 连续“帮我搬一块”后达到 4/4；外框 49，四块三角形共 24，剩余 25 | 辅助完成与面积证据联动；点击四次不证明掌握勾股定理 |
| E04 截面 | 中心预设得到 6 顶点、面积 5.196；方位角 63°、仰角 50°、偏移 0.4 得到 5 顶点、面积 4.251 | 五边形可找到；按给定数值复现不代表能解释顶点来源 |
| E05 纸带 | 莫比乌斯带剪切至 100% 得到一条双面带；双半扭转带得到两条套连带；错误预测有反馈 | 已有连续剪切和剪后追踪入口，不应再次建议“从零增加剪切过程” |
| E06 月相 | “满月，无月食”本影覆盖为 0%；真实倾角下调整到满月与交点对齐，月食挑战达到 100% 并通过 | 支持月相与月食区分；不支持真实日期、地表地点的食预报 |
| E07 轨道 | 椭圆预设近/远地点高度约 1500/7140 km；8 km/s 向地心时提示负能量轨道仍会穿地 | 能量与几何条件均有证据；不是完整火箭发射 |
| E08 三体 | δ=0 提示两边一致；微扰演示快放后 RMS 从约 0.000577 增长到约 0.249490 | 该次运行出现分离；读数依赖停止时刻，不能据此证明所有三体都混沌 |
| E09 桥梁 | 加 A–E、C–E 后通过长度与模型稳定挑战；40 kN 时反力 20+20，改为 80 kN 后为 40+40 | 结构与载荷联动；模型稳定不能直接推断真实承载安全 |
| E10 重心 | A/B 只降高度，重心高 62.50→36.00 cm，余量 16.72→22.35 cm；运输挑战通过；同比加倍质量的临界角不变、恢复力矩加倍 | 已有固定条件对照与迁移验证，下一步应增强解释与可发现性 |
| E11 齿轮 | 输入 20 齿、输出 60 齿，加中间轮得到 4 rpm、同向；中间轮改成 50 齿后输出仍为 4 rpm | 首尾比与中间轮作用可验证；未测真实机械效率 |
| E12 手机布局 | 十二页在 390 px 下均无页面级横向溢出；已操作状态下透镜约 6475 px、月相 6451 px、重心 6736 px 长 | 长页面可能增加往返成本；高度受展开状态影响，不代表真实手机性能或必然造成卡顿 |
| E13 浮力 | 生产预览中浸入 0/5/10 cm，浮力为 0/5/10 N、拉力为 27/22/17 N；完全浸没换密度 1200 后为 12/15 N | 浸入与液体密度对照可用；当前滑块不能验证完全浸没后继续下沉 |
| E14 单摆 | 生产预览中 3 kg 主摆与参考摆释放后，实测周期 2.52 s，与完整理论值 2.52 s 一致 | 周期测量可运行；这一次读数不替代多参数精度验收 |

本地开发预览一度出现依赖请求 `504 Outdated Optimize Dep`：浮力滑块读数未更新、单摆停留在“正在准备实验装置”。其余使用 Three.js 的实验切换为二维降级。随后用当前源码生产构建的静态预览重新操作，浮力与单摆恢复正常，相关证据见 E13/E14。这次异常归入开发缓存问题，不列为已证实的线上缺陷。生产预览中三维场景可显示，透镜三维截图随报告保存；没有实施三维直接拖动与相机操作的全面验收。

本次浏览器操作覆盖每个实验的代表任务，不包含所有控件组合、所有挑战、真实触屏拖动、低端手机、弱网或辅助技术全面验收。开发预览的降级画面与生产预览的三维画面分开判断。既有项目验收文档只作为背景，不冒充本次新测结果。

## 4. 逐人、逐实验记录

下列表格中的第一人称表达全部是反馈，不是真实引语。“收获”指该路径可能支持的理解，需要通过复述或新任务确认。

### 4.1 S1 林芽：先看见，再给现象命名

| 实验 | 操作与体验反馈 | 可能收获 | 针对改进 |
|---|---|---|---|
| 浮力 | 在三种浸入状态间切换：“我看到拉力变小，但排水是把水倒掉吗？”cm³ 与 kg/m³ 会打断阅读 | 水分担部分重力；排水体积指物体占去的液体空间 | 在体积读数旁点亮对应水体，并提供“被物体占去的水空间”释义 |
| 单摆 | 先释放，再换月球：“月球上更慢，但我不知道一个来回从哪里数。”看到耗散栏不知“耗散”含义 | 高处与低处的速率不同；重力改变周期 | 加一次完整往返的可暂停标记，把“已耗散”解释为转为内能的部分 |
| 透镜 | 用首次任务只移动光屏：“F 清楚了很有成就感。放大镜为什么屏上看不到？” | 光屏要到合适位置才清晰；眼睛看到的像不一定可接到屏上 | 保留首次调焦；进入虚像时突出“现在看眼睛观察窗”，再解释术语 |
| 面积 | 先辅助搬一块，再跟着拼：“我知道黄色一样多，但 a² 不像我画过的面积。” | 刚性搬动不改变面积；相同外框减相同拼块，剩余相等 | 可点 a² 高亮对应正方形，把符号与图形对应，而非只追加公式 |
| 截面 | 点三角形、六边形，再试平移：“像切水果，但左图哪条线是切出来的？” | 同一立体可有不同截面；截面顶点来自棱上的交点 | 点右图顶点时同步高亮左图对应棱，建立两图对应 |
| 莫比乌斯 | 预测剪开两条，再看只剩一条：“我猜错了，想亲手沿它一直走。” | 连接关系比颜色可靠；中心剪开不一定变两条 | 保留逐段剪切与剪后追踪；明确第一步沿面、第二步沿边，不同时介绍全部术语 |
| 月相 | 先选上弦与满月：“原来不是地球影子每天挡住月亮。交点还是不知道在哪。” | 月相来自受光面与观察方向；月食另需对齐 | 提供“找轨道与黄道交叉的两个点”小任务，先看交点再调方向 |
| 卫星 | 选太慢、圆轨道：“它没开引擎也能转？切线是什么意思？” | 引力拉向地心，初速度让卫星向前运动 | 用箭头直接示范“沿圆边向前”，再引出切线；首轮隐藏高阶轨道量 |
| 三体 | 两边同时运动：“像两张差不多的画，我不知道该盯哪颗。” | 相同规则、略不同起点可能导致不同后续 | 先只高亮一对对应星，锁定同一时刻暂停，再引导看总差异 |
| 桥梁 | 用节点按钮连接斜撑：“我能让它稳定，但红色是不是断了？” | 三角形斜撑限制框架变形；受力不等于破坏 | 首次出现红杆时在近旁标“受压，未损坏”，并提供捏压日常类比 |
| 重心 | 做低配重对照并松开：“它站住了，金点不等于蓝色重物的位置。” | 整体重心由架与配重共同决定；落点在支撑范围内更稳 | 先用生活语言介绍 G，再开启固定条件对照；保留真实释放检验 |
| 齿轮 | 改大输出轮、加入中间轮：“大轮慢一点，但扭矩是不是速度？” | 大输出轮转得慢；中间轮改变首尾转向 | 用同一把曲柄的力臂示意解释扭矩，保留转数盘作为直观证据 |

**总反馈：**“我最想再玩纸带和月亮。每页先告诉我做哪一件事，会比让我先认很多符号更好。”  
**学习核验：**让她画出上弦月的受光方向、解释为何剪开仍相连，并在新配重位置上先猜再释放。能够画出与解释，才算超越跟随按钮。

### 4.2 S2 周屿：从做对一道题，走向解释一般规律

| 实验 | 操作与体验反馈 | 可能收获 | 针对改进 |
|---|---|---|---|
| 浮力 | 固定浸入体积、切换密度：“数值代入很好，但完全浸没后不能再往下，怎么验证深度无关？” | 浮力取决于液体密度与排水体积；部分浸入时深度只是体积的代理 | 当前滑块止于 10 cm；增加独立下沉位置对照，或明确该结论此处仅解释未实操 |
| 单摆 | 质量设 3 kg 与参考摆对照，再改摆长：“质量不影响周期，我想检验摆长四倍会怎样。” | 控制变量；小角度周期与摆长平方根相关 | 提供两组周期记录与 L 比、T 比对照，注明角度和阻尼条件 |
| 透镜 | 调到 u=2f，再到焦点内：“像距负号很好用；我想先预测，再看理论值。” | 成像区间与正负号规则，屏距与理论像距不同 | 增加可选“先隐藏理论值”，提交预测后再显示；不撤走自由探索 |
| 面积 | 先用 3、4，再换非整数边长：“计算对了，但不能只用测出的 c 去证明 c²。” | 面积消去给出一般证明，数值用于检验 | 区分“数值检查”与“面积证明”，要求说出外框相同、四块全等这两个理由 |
| 截面 | 独立找五边形：“找到以后还想知道为什么不可能有七边形。” | 平面与凸多面体各面相交形成截面边；顶点数有上界 | 增加六个面的相交高亮与解释题，避免只给“最多六个”结论 |
| 莫比乌斯 | 比较 0、1、2 次半扭转：“面数看奇偶，但剪后套连好像不能只看奇偶。” | 纸面、边界、连通分支、套连是不同性质 | 增加空白比较表让学生填观察，再揭示说明；沿用现有剪后追踪 |
| 月相 | 固定满月只转交点：“满月不是月食的充分条件，条件关系很清楚。” | 必要条件与额外对齐条件的区别 | 让学生选一组“满月但无月食”反例并写一句解释 |
| 卫星 | 保持 8 km/s，方向由切向转向地心：“负能量为什么也会撞？这个反例很有用。” | 有界轨道与不撞地球是两个不同条件 | 保存两组同速不同方向轨道，近地点与地表一起比较 |
| 三体 | δ=0、0.001、0.01 顺次运行：“停下来的时间不同，数字就没法直接比。” | 对照需要同一观察时刻；分离不一定单调 | 加“运行到 t=…”与参数快照，保持能量误差独立显示 |
| 桥梁 | 斜撑稳定后把载荷翻倍：“反力和杆力一起变，想知道线性关系在哪些条件下成立。” | 对称受载反力分配；线性小变形模型的比例关系 | 挑战后增加偏心施力对照，先预测两支座反力是否仍相等 |
| 重心 | 留 A、降低 B，再同比加倍质量：“不是重就更稳，而是质量分布要看比例。” | 重心是加权位置；同比加质量不改变几何翻倒临界角 | 保留已有迁移验证，再要求说明公式分子分母同时加倍 |
| 齿轮 | 自己配置 20:60 与中间轮：“能算出 1/3，想先填答案再看自动读数。” | 齿数反比决定速度，理想扭矩与齿数正比 | 提供可选预测模式，区分方向符号与速率大小 |

**总反馈：**“最有价值的是能找到反例，而不只是让答案变绿。我愿意做一个没有预设按钮的新题。”  
**学习核验：**给出不同边长的面积拼图、同速不同发射角、非对称桥梁载荷，检查能否把原理迁移到新情境。

### 4.3 S3 陈桥：从调参过关，走向有依据的工程选择

| 实验 | 操作与体验反馈 | 可能收获 | 针对改进 |
|---|---|---|---|
| 浮力 | 先播放入水，再换液体：“我想换木块看它浮起来，但这里只有被吊着的铝块。” | 吊绳拉力与浮力分担重力；悬挂与自由漂浮不同 | 首次操作旁明确“本台研究悬挂物体”；自由漂浮作为后续独立模式评估 |
| 单摆 | 打开阻尼与受力：“我想做摆锤装置，最下面绳子是不是拉得最紧？” | 最低点速率大；张力包含提供向心加速度所需部分 | 任务入口突出“最快处拉力多大”，加最高点/最低点暂停比较 |
| 透镜 | 不看演示直接拖光屏：“自己调清楚像真的在对焦。换物距后想保留刚才那一组。” | 调焦依赖物距；记录与恢复能减少重复设置 | 把已有“记下这一刻”在首次调焦成功后用就近入口带出 |
| 面积 | 连续点辅助后尝试自己拼：“帮我放好容易，但自己转错了不知道差在哪里。” | 平移旋转保持面积；朝向影响拼合而不改面积 | 在自主模式中对未就位块提供按需方向提示，而非自动完成全部 |
| 截面 | 想用拖动改变看立方体的角度：“旋转切面与旋转物体不是一回事。” | 观察视角与切平面参数必须区分 | 当前左图固定视角；先明确此限制，再评估增加独立可复位观察视角 |
| 莫比乌斯 | 跟实体纸条建议制作：“屏幕让我知道结果，纸条让我相信它。” | 通过沿边与剪切验证连接关系 | 提供可打印的三种纸带预测/观察记录卡，继续强调不凭颜色数条数 |
| 月相 | 先按月食预设再自己对齐：“预设漂亮，但我不想靠点答案完成挑战。” | 对齐需同时满足相位和交点条件 | 挑战中显式标注预设是在载入示例，独立完成另给一组起始条件 |
| 卫星 | 以为发射是从地面升空：“页面从高空给速度，名字让我预期会调火箭。” | 一次初速度与持续推力是两种问题 | 在发射按钮旁简写“已在高空，仅设置初速度”，保留完整模型说明 |
| 三体 | 随意改变质量与速度：“很好玩，但我不知道哪次改动造成了差别。” | 多变量一起改不利于归因 | 增加本次改变项摘要与一键恢复上组；入门任务暂锁其他变量 |
| 桥梁 | 裸框→两根斜撑→拆一根：“能看到拉压，比只有承重分数有用。是不是三角形越多越好？” | 稳定性、材料用量与杆力分布是不同目标 | 保留 18 m 限制，加入两种稳定方案比较；不得将高载荷下仍稳定称作材料安全 |
| 重心 | 运输挑战中先把底座加宽：“最容易通过，但现实车宽有限，我想比哪个改法更省。” | 降重心和加支撑均能增加余量 | 增加可选支撑宽度上限，以现有高度对照解释方案取舍 |
| 齿轮 | 配 20:60 并改中间轮：“小轮带大轮更有劲，那是不是免费多了能量？” | 减速换理想扭矩，功率不凭空增加 | 增加输入/输出功率同屏代入及一个错误解释纠正题 |

**总反馈：**“桥梁、重心、齿轮像能解决实际问题。我希望保存两个方案，告诉别人我为什么这么搭。”  
**学习核验：**给出“底座不能再加宽”的运输任务、不同载荷位置的桥梁、首尾同向的减速传动，要求说明取舍。

### 4.4 S4 许星：把直观天文图景与物理条件对应起来

| 实验 | 操作与体验反馈 | 可能收获 | 针对改进 |
|---|---|---|---|
| 浮力 | 比较密度并读取压强：“底部压强在变，我差点以为浮力就等于底面压强乘面积。” | 浮力来自压强差；绝对压强不是浮力 | 将压强读数放入进阶证据，增加上下表面压力对照，避免只突出底部 |
| 单摆 | 比较地球和月球、小角和大角：“小角近似与完整理论值一起显示很有帮助。” | 近似公式有条件；重力与摆长决定主要周期尺度 | 增加角度—周期偏差记录，保持实测与理论值的区别 |
| 透镜 | 逐个成像区间，比较 F 的方向：“虚像是反向延长线交点，不是光真的倒着走。” | 几何光路、观察虚像与屏幕成像的区别 | 在虚像模式按需演示一束实际传播方向，眼睛观察窗保持可见 |
| 面积 | 用面积守恒解释，再改边长：“这种证明方式比背公式更有记忆点。” | 几何不变量与一般论证 | 提供“请用两句话说明为什么任意直角三角形都成立”的出口题 |
| 截面 | 调平面方程并观察面积：“顶点数不变时面积仍会变化。” | 拓扑类型与度量大小不是同一变化 | 让学生保留两个六边形，比较是否正六边形、面积是否相同 |
| 莫比乌斯 | 沿面走两圈再比较纸边：“我开始能区分绕中心圈数与边界条数。” | 单面性是全局命名问题；路径圈数不等于边界数量 | 在读数旁放三个小图例：绕中心、沿边、完整带，减少名称混淆 |
| 月相 | 满月无食→转交点→日全/环食：“空间和地球所见的对应是最有价值的部分。”也会问能否查下次月食 | 月相看夹角，月食看地影，日环/全食还看视大小 | 把“教学快照，不是日期预报”放到时间进度旁；交点先标清再演示 |
| 卫星 | 比较圆与椭圆的半径、速率：“负势能与总能量很清楚，但图上箭头不能一起比长度。” | 引力改变速度方向；椭圆中动能与势能交换 | 将箭头独立缩放说明贴近图例，选择近地点/远地点可对照状态 |
| 三体 | 先八字后近遇：“我原来以为三体必定乱飞，现在知道初态不同。” | 规则确定不保证长期易预测；特殊轨道与敏感运动可并存 | 加反例提问：这次八字轨迹能说明所有三体都稳定吗？ |
| 桥梁 | 改中央为偏侧受载：“反力不再平分，能看见载荷传到支座的路径。” | 对称性条件影响反力分配；拉压传力 | 点支座时联动相关反力与平衡式，避免只看杆色 |
| 重心 | 将配重偏侧并左右倾斜：“向左和向右临界角不同，和经验对应上了。” | 重心偏移导致方向性稳定差异 | 给一项左右倾角比较记录任务，不把“更稳”当无方向结论 |
| 齿轮 | 看扭矩与速度条：“理想功率守恒，但实际装置会损耗，页面边界说明是必要的。” | 理想关系与实际效率不同 | 先用现有理想模型完成解释，摩擦效率作为拓展阅读，不直接添多个新滑块 |

**总反馈：**“月相和轨道最值得反复来。希望观察图、参数和判断能一次保存在同一张记录里。”  
**学习核验：**用“满月但无月食”“负能量但撞地球”“三体特殊八字”三个反例检查能否准确说明条件。

### 4.5 S5 顾遥：把互动装置变成可复现的数值探究

| 实验 | 操作与体验反馈 | 可能收获 | 针对改进 |
|---|---|---|---|
| 浮力 | 准备拟合 F浮 与 V排：“变量很清楚，但需要手抄各组数据；g=10 与别页 9.81 要分清。” | 定量模型、单位换算与实验约定 | 提供带单位和 g 值的多组记录/CSV；不要跨实验默认为相同常量 |
| 单摆 | 比较理论、实测与小角近似：“想把角度从 10° 到 70° 的误差画出来。” | 非线性修正与测量定义；数值演化可作实验 | 导出初态、两次同向过零时间、周期和阻尼；先提供实验记录再考虑可调积分步长 |
| 透镜 | 保存六组并恢复：“已经有持久记录和两组比较，很接近研究台。还想导出而不只是截图。” | 记录固定量/变化量；有符号像距与模型适用范围 | 在现有本地六组记录上增加导出与备注；不用账号替代轻量记录 |
| 面积 | 检查 c 是如何得到：“画面用 sqrt 算 c 合理，但数值等式不能成为证明本身。” | 实现中的计算与数学论证需要分开 | 将一般面积消去作为主要论证，计算读数明确为数值核对 |
| 截面 | 用同一方向扫描偏移：“想比较顶点切换时面积是否连续。” | 截面形状类别可变化，度量可以连续演变 | 增加采样记录，导出平面参数、交点、面积、周长，并注明退化条件 |
| 莫比乌斯 | 比较剪前后不变量：“连通带数、边界数和套连不能用一个指标概括。” | 参数曲面与连接关系的区别；剪切改变拓扑 | 允许导出 0/1/2 次半扭转的观察表，要求沿路线验证而非只读模型答案 |
| 月相 | 核对角大小与本影覆盖：“纹理逼真容易让我忘记距离被压缩；应分清展示和计算尺度。” | 角大小决定遮挡；示意比例与判定模型可分离 | 在空间图旁设“示意尺度”说明，导出计算用真实参数；继续禁止冒充历书 |
| 卫星 | 用负能量的穿地轨道作反例：“能量守恒检查有帮助，想比较一整圈误差。” | 守恒量是数值可靠性检查，几何碰撞需独立判断 | 导出 r、v、ε 与时间，显示相对能量偏差；固定步长先保持一致 |
| 三体 | 对比 δ 并观察 RMS 与能量误差：“不能拿轨迹差异当数值误差，更不能一次截图就说混沌。” | 初态敏感性、有限时域证据与积分误差的区分 | 最高需求是统一停止时间、初态快照、CSV 与误差字段；近遇保护原因要留在记录里 |
| 桥梁 | 看刚度模型与线性受力：“没有假承重分数很好，想比较两种相同杆长方案。” | 模型可解、结构稳定与材料失效不是一回事 | 导出节点、杆件、EA、载荷、反力与位移放大倍数；保持真实值和展示值分开 |
| 重心 | 复核质量同比加倍：“现有验证很到位，临界角不变但力矩翻倍正好能讨论无量纲比例。” | 量纲、加权位置与几何稳定判据 | 导出 A/B 与质量加倍结果，添加“只加配重”对照的预测题 |
| 齿轮 | 验证中间轮任意齿数：“公式很容易核对，但转数与瞬时速度可以分别记录。” | 传动比、转向奇偶与理想功率守恒 | 增加带时间的累计圈数导出，记录首尾及中间轮齿数 |

**总反馈：**“不需要每个实验都做得更复杂。先让我保存条件、停在同一时刻、导出单位完整的数据，就能自己研究。”  
**学习核验：**要求写出一份可复现的三体对照协议，说明固定条件、停止时刻、误差判据和结论范围。

## 5. 跨角色产品体验

| 产品环节 | 实查基础 | 中的不同反应 | 改进方向 |
|---|---|---|---|
| 发现入口 | 四个空间、十二张卡片与主题路线已有；卡片没有统一的先修/任务耗时提示 | S1 不知哪个无需物理基础；S3 会直奔建造；S5 想直达定量任务 | 卡片注明“先做什么、需要哪些知识”，预计时长经真实试用后再发布 |
| 第一次动手 | 透镜明确只调光屏；六个 SVG 实验有标准演示；单摆有任务准备 | S1 喜欢单一步骤；S2、S3 容易把演示结束当自己已掌握 | 维持各自装置风格，统一最低学习要求：观察一次、独立改变一个量、说出一个理由 |
| 内容层次 | 原理、证据、挑战、边界丰富；页面长且顺序不同 | S1 跳过公式；S4 需要模型假设；S5 找高级参数与记录 | 按任务折叠“解释/进阶”，允许随时展开；按经验选择，不硬锁年级 |
| 手机往返 | 四个近期实验已有实时观察条；透镜还有光屏取景窗 | S1 可以看数值，但月相与纸带变化仍需回画面判断 | 在现有观察条上检验任务相关小预览或定位锚点；先实测往返次数再决定方案 |
| 记录与回访 | 透镜最多六组本地持久记录；重心 A/B 仅当前页；其他实验缺少统一记录路径 | S3 想保存方案，S4 想保存状态，S5 想复现数据 | 建立可选轻量记录格式：问题、预测、条件、观察、解释；尊重各实验不同数据 |
| 路线与导航 | 十个 `/labs/` 使用主站布局；浮力、单摆有独立导航；浮力未进入四条主题路线 | S1 可能反复返回首页；S2 会问为何“光”路线下一步是摆 | 补全浮力路线归属；说明透镜→单摆连接的是测量/控制变量，并提供直达目录入口 |
| 过关判断 | 多个挑战基于条件计算，反馈通常邀请解释 | S2、S3 可以调到通过却不一定说清；S5 会关心判据 | 保留即时反馈，增加一项反例或新条件题；无需强制长文本提交 |
| 加载与降级 | 多个实验有二维降级；开发依赖缓存异常曾导致两个实验无更新，生产预览复核正常 | 所有角色都可能把加载失败误认为自己不会用 | 开发问题已隔离；将独立就绪状态、超时提示和最小可互动降级作为可靠性增强建议 |

不建议首先增加排行榜、全站积分或注册门槛：当前暴露的主要问题是解释和证据连续性，积分不能验证理解。本地记录与导出可先支持回访，跨设备同步须有真实需求再决定。

| 第一批 P1 | 首次任务与误解提示 | 浮力、单摆、截面、月相；透镜只补已有成功任务到记录的连接 | 一页只给一个首次目标；不看长文能启动；学生在新条件下作预测并指出证据 |
| 第二批 P1 | 留下对照证据 | 三体同刻停止、各实验轻量记录；复用透镜记录与重心 A/B 经验 | 记录含固定量、改变量、单位、时间和结论范围；恢复不自动播放 |
| 第三批 P1/P2 | 手机任务闭环 | 先研究透镜、月相、重心三个长页面，补任务定位与必要预览 | 同一探究任务能连续看见操作反馈；与现版比较画面/控件往返次数，且不遮挡装置 |
| 第四批 P2 | 解释与迁移 | 十二实验各一题，不扩大核心操作复杂度 | 通过按钮判定后，能在新条件题中说明原理；错误反馈指出证据而非只显示错 |
| 后续 P3 | 新实验模式 | 自由漂浮、真实天文观测等，先明确模型和需求 | 单独做需求和科学验收，不混入现有简化模型 |

## 7. 将转化为真实学生验证

建议下一轮邀请不同年级、不同学科基础的实际学生；同龄也覆盖不同经验。五人小样本适合发现卡点，不用于推断整体学习效果。无需让每人一次连续做完十二实验。

采用两轮：第一轮每人选一个熟悉主题、一个陌生主题，观察首次使用；第二轮补齐实验覆盖，针对主要卡点测试改版。保留自愿参与、基本设备条件和是否接受过相关课程的记录。

记录以下事件，而不是只问“喜欢吗”：

| 观察项 | 记录方式 | 对应决策 |
|---|---|---|
| 首次有解释的变化 | 从进入页到第一次能说出“我改了 X，Y 变了”的时间与操作 | 判断入口和提示是否足够 |
| 卡点 | 具体控件、学生原话、是否求助、求助内容 | 区分术语、操作、概念和加载问题 |
| 手机往返 | 为完成同一任务在画面/控件/证据之间的滚动或定位次数 | 判断观察条、取景窗、锚点哪个真正有用 |
| 控制变量 | 是否同时改变无关量，能否指出固定条件 | 判断对照任务是否成立 |
| 解释质量 | 0：只报结果；1：说关系；2：引用证据解释；3：能说明条件/反例 | 作为观察编码，不直接叫标准化学习分数 |
| 迁移 | 不用预设的新条件题；记录预测、证据与是否修正 | 区分“跟着做对”与“独立理解” |
| 回访 | 间隔后能否恢复条件并复述发现 | 判断记录是否有实际学习用途 |

建议直接问学生：“刚刚你只改了什么？”“哪条证据让你改变想法？”“如果换一个条件，你预测会怎样？”不要先提示正确概念，再把跟读当掌握。

优先真实验证任务：S1 型完成纸带剪后追踪与月相解释；S2 型完成非整数面积论证与五边形交点；S3 型完成受宽度约束的运输方案；S4 型解释满月无食与负能量穿地；S5 型提交同一时刻的三体对照。每个任务都记录实际卡点，允许结果推翻本报告的角色推演。
