## GitHub 本轮核查与取舍

本轮实际读取四仓库的 GitHub API 元数据与默认分支 README，没有把 README 阅读写成在线交互产品实测。下面“借鉴”是基于已有产品调研与本轮仓库资料所作的设计选择。

| 参考 | 本轮读到的资料 | 本站采用的思路 |
| --- | --- | --- |
| [PhET circuit-construction-kit-dc](https://github.com/phetsims/circuit-construction-kit-dc) | 描述为 HTML5 电路教学模拟；README 明确声明旧仓库不维护，重整为尚未公开的 monorepo；API 的 archived=false 不等于仍维护，license=null 不等于无约束 | 连接器材、实时测量、控制变量。独立实现小而完整的六端口工作台，不依赖旧仓库运行库 |
| [Mathigon textbooks](https://github.com/mathigon/textbooks) | README 为12–18岁互动数学教材，每课结合 content、functions、styles 与 hints；README 标注 All rights reserved，API license=null | 让对象可操作，文字跟着问题出现。用原生按钮与 SVG，把端点、导线与灯做成学生能直接改变的对象 |
| [Ray Optics](https://github.com/ricktu288/ray-optics) | README 列出案例画廊、测量、CSV、折射、色散、光强图等；API 报告 Apache-2.0 | 示例进入自由探索，保存条件再比较读数。为下一项折射实验保留有依据的参考方向 |

本轮无第三方代码、图像、商标或运行库导入。仪器图形与模型原创；具体复用某文件时仍需逐文件核查对应版本许可。PhET 与 Mathigon 的仓库元数据不足以授权代码或素材复用。

## 已落地：电路接线工坊

问题：“少一盏灯，另一盏还亮吗？”第一分钟只补一根回线，随后从空板给两灯各找通路。接线本身是学习动作，短路/断路诊断、灯功率、独立断灯挑战与两组记录构成证据链。1800 年伏打电堆提供历史入口。

独立电源内阻模型避免“并联完全互不影响”的绝对化说法；示例、恢复与个人操作明确区分。详见[操作与验证指南](circuit-wiring-user-guide.md)。

## 已落地：电阻与电容

按电学拓展建议新增电阻分压台“6 V怎样分出3 V？”与电容时间台“电源断开，电压还在吗？”。前者检验负载使分压改变，后者区分开路保持和经电阻放电；均提供历史引子、首次任务、实时测量、两组证据和CSV。详见[操作与验证指南](resistor-capacitor-user-guide.md)。

## 接下来的候选顺序

| 优先 | 实验与吸引点 | 借鉴方向 | 模型与首个验收判据 |
| --- | --- | --- | --- |
| 下一项 | **光的转弯：让一束光留在水里**，转动光束跨越临界角，发现全反射 | Ray Optics 的界面折射与案例；延续本站透镜光学路线 | 平面界面、斯涅尔定律、临界角与反射角。水到空气约48.6°临界角；空气到水不能出现全反射；光强若呈现必须用一致的能量模型 |
| 第二项 | **折起一座立方体**，给六块面选铰链，预测哪两面会撞在一起 | Mathigon 的几何对象操作 | 面邻接/铰链树与刚体折叠，明确有效展开图和重叠，不把动画到位当作正确。预设有效网格与无效反例分别验证 |
| 第三项 | **看不见的行星：光变侦探**，从一条亮度曲线猜遮挡大小，再揭示轨道 | 短互动解释与本站月相双视角证据 | 均匀亮度圆盘的遮挡面积、轨道投影。中心凌日深度为半径比平方；说明未模拟临边昏暗，不能从单次理想曲线宣称识别真实行星 |
| 后备 | **分子的散步：扩散没有指挥官**，打开隔板，看随机运动形成整体趋势 | Nicky Case 从局部规则到整体结果的互动叙事 | 可复现随机种子、粒子数/碰撞与浓度统计。对照相同初态与种子，展示涨落，不用一次随机曲线冒充必然单调规律 |

每项独立做 OpenSpec 提案、模型、任务、浏览器验收与归档，完成一项后再定下一项的具体范围。选择标准：有独特动手动作、能留下两组可复现证据、有可解释反例、模型能核验、手机能完成主要任务。每个新实验从首版就补历史背景，保留自由探索，不以强制剧情或全站积分代替理解。

旧规划 B–E 的记录、手机路线与迁移任务仍为后续工作；新增实验不表示这些全站工作已完成。真实学生试用仍需单独进行。
