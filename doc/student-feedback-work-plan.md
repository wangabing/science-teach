# 学生模拟反馈驱动的后续工作计划

日期：2026-10-16。状态：A批已实施并验证；B–E保留后续规划。新增双源波纹实验另见交付指南。

依据：[原产品打磨规划](product-polish-benchmark-review.md)、[学生模拟体验报告](student-simulation-experience-report.md)。本计划最初按“先不用实现代码”交付；后续获得实施授权后，已完成A批代码与验证。

## 1. 产品方向与证据边界

保持产品初心：让学生亲手改变条件、看见现象、保留证据，逐步形成自己的解释。创意落在有意义的动作上：给截面顶点找“出生的棱”、给单摆标记一次往返、找出躲开地影的满月；各实验保留自己的装置和风格。

报告的五位学生是虚构角色，60 条体验记录是角色推演。报告中的生产预览操作与当前源码可支持功能判断，但不能证明学生真的遇到这些卡点或已学会。本计划区分三类依据：

- **代码核对**：本轮读取页面、脚本或模型确认的行为。
- **报告实查**：报告记录的生产浏览器操作，本轮未重新运行。
- **角色假设**：需要真实学生使用才能判断的理解与体验问题。

原规划三个代表实验已有工作区成果：透镜首次调焦/手机取景窗/六组本地记录，重心锁条件 A/B 与质量加倍验证，纸带逐段剪切与剪后追踪。本轮以这些能力为基线，不重复列为待开发。

## 2. 交付顺序与停止条件

| 顺序 | 交付包 | 主要成果 | 进入下一阶段的条件 |
|---|---|---|---|
| 条件性 P0 | 加载可靠性 | 生产环境复现时处理就绪、降级与失败提示 | 有可复现生产证据才升级为阻断项；报告最终复核未复现 |
| A / P1 | 首次任务与就地提示 | 浮力、单摆、截面、月相；透镜成功到记录的连接 | 科学边界、独立操作来源、键盘与窄屏检查通过，再做首次使用观察 |
| B / P1 | 留下可复现对照 | 三体同刻停止；可选轻量记录；逐实验接入 | 固定条件、变量、单位、仿真时间与恢复行为可核验 |
| C / P1–P2 | 手机任务闭环与路线 | 三个长页的任务定位/必要预览；浮力路线归属 | 与现版按同一任务比较往返操作，无遮挡；覆盖真实触屏设备 |
| D / P2 | 解释与迁移 | 十二实验各一项新条件或反例题 | 错误反馈能指向当前证据；真实观察区分调参达标与解释 |
| E / P3 | 新模型或内容 | 自由漂浮、扩展深度模型、真实观测等独立提案 | 有明确需求、科学模型和独立验收协议 |

A 先形成稳定任务对象，B 才能记录有意义的条件，C 再围绕这些任务调整布局，D 利用操作和记录作解释。真实学生试用从 A 的原型即可开始，不必等待全部开发完毕。B 内三体同刻停止可独立推进；全站记录按实验逐个接入，避免一次性大改十二页。

## 3. A 批：首次任务与误解提示

对应 OpenSpec：[clarify-first-experiment-tasks](../openspec/changes/archive/2026-10-16-clarify-first-experiment-tasks/proposal.md)。五个实验均只突出一个首次目标，保留自由探索，不用强制步骤锁住装置。

| 编号 | 依据与问题 | 具体工作 | 验收用例 |
|---|---|---|---|
| A1 浮力 | 代码核对：浸入范围 0–10 cm；完全浸没后无法继续下沉。报告 §6 与 S1/S4 建议明确排水体积 | 首次只改浸入深度，联动浸没部分与 V排；明确“当前不能验证完全浸没后继续下沉”；密度比较作为下一步 | 水中 0/5/10 cm 对应 0/500/1000 cm³、0/5/10 N、张力 27/22/17 N。10 cm 的边界可见，不把预设称为独立验证；g=10 m/s² 就近可查 |
| A2 单摆 | 代码核对：两次正角到负角过零的插值时间差已计算；当前周期卡不显示两次时间 | 标出同向过零起终点、方向与测量阶段；手动保存当前页两组完整测量；比较固定量/改变量 | T=t₂−t₁；中间反向过零不结束计时；改参数/重新释放清除当前计时但保留已存组；两组不能把多变量变化标为单变量证据 |
| A3 截面 | 代码核对：双视图展示相同交点，但没有原棱来源联动。报告 S2/S4 | 顶点编号关联原立方体棱；提供可键盘操作的编号列表，与两图选择联动 | 方位 63°、仰角 50°、偏移 0.4 的报告五边形案例先由模型复核；五个顶点均可找到来源；经过原顶点的交点合并，点/线不冒充多边形 |
| A4 月相 | 代码核对：已有交线、满月无食预设和交点演示；挑战只检查当前参数/结果 | 标出两个交点及其所在平面；从满月无食准备任务，只改交点找月食；预设/演示与独立验证分开 | 固定相位180°、倾角5.145°、距离60.27 R⊕，node90° 无食，手动转到0° 可得到月全食；预设/演示不能直接取得独立完成；时间读数旁说明教学快照不是预报 |
| A5 透镜 | 代码核对：首次成功文案已邀请记录，但记录按钮在后面；虚像已有观察窗 | 成功旁放记录动作和再调焦入口，共用现有记录逻辑；虚像就近定位眼睛观察窗 | 无预设手动调清晰，附近即可存入六组记录；改变物距再调焦得到第二组；满额/存储失败不谎报成功；虚像引导不暗示投屏成像 |

浮力第一批采用“明确不可实操”的范围，不扩展装置深度；要验证完全浸没后深度独立变化，另做水槽、物体位置、压力差与控制量一致的设计。单摆两组记录仅当前页，B 批再做持久化与导出。

## 4. B 批：留下可复现的证据

报告 §5、§6 及 S5 的共性需求是记住条件与比较时刻。采用“我的发现卡”：问题、可选预测、条件、观察、可选解释。个人文字可跳过，不能把空白解释称为已理解。

| 编号 | 工作 | 验收标准与依赖 |
|---|---|---|
| B1 | 三体共同停止时间与初态快照 | δ=0、0.001、0.01 分别从相同基线启动，在同一仿真 t 停止；跨越目标的最后一步不靠墙钟或帧数近似。近遇保护提前终止则记录实际停止时间/原因，不宣称同刻结果 |
| B2 | 记录格式与本地存储策略 | 版本、实验类型、条件、固定量/变量、单位、常量、仿真时间、模型结果与适用范围分离；结果恢复后重算；坏数据和不支持版本可解释处理；有容量限制、单条删除与清空 |
| B3 | 三体、单摆、月相优先接入 | 三体记录质量/位置/速度/扰动、RMS与独立能量误差；单摆记录两次过零、角度、阻尼和重力；月相记录计算参数和示意尺度说明。恢复均暂停，历史曲线若未保存不得伪造连续历史 |
| B4 | 透镜与重心复用已有能力 | 透镜保留兼容的六组记录，增可选备注/导出；重心保存 A/B 固定条件、质量加倍结果。状态变化使派生验证过期，不能恢复为仍有效的挑战通过 |
| B5 | 其余七实验逐个接入 | 浮力含 g 与体积；面积含一般论证与数值核对区分；截面含平面/交点/面积/退化；纸带含预测与追踪结果；轨道含时间/r/v/比能；桥梁含节点/杆/EA/载荷/反力/展示放大倍数；齿轮含各轮齿数/时间/累计圈数 |
| B6 | 文件导出与回访验证 | JSON 用于完整条件复现，CSV 用于该实验量表；含单位、字段说明、模型版本；验证数字与页面一致、特殊字符安全处理。刷新/离线回访/禁止存储时行为明确，无账号依赖 |

优先做 B1+B2+B3，再用 B4 验证兼容迁移，最后 B5 逐实验验收。暂不设计跨设备同步或分享参数 URL；已有本机记录不足以推断这两项的真实需求。

## 5. C 批：手机闭环与路线衔接

| 编号 | 工作 | 验收方法 |
|---|---|---|
| C1 | 建立现版任务基线 | 透镜两次调焦、月相满月交点对照、重心 A/B 各按同样协议记录画面/控件/证据往返次数；报告页高只说明页面长，不能直接当体验差的结论 |
| C2 | 任务锚点与小预览试做 | 先提供回装置/参数/证据定位；月相仅在需要处显示地球所见月面与影区，重心显示重力线与支撑面；透镜沿用已有取景窗。对比原型后决定布局，不先把三页全部固定吸顶 |
| C3 | 触屏、键盘与显示检查 | 320/390 px 无页面级横向溢出；设备软键盘打开、横屏、200%缩放不挡主要控件；预览与原装置共用同一模型状态；真实手机检查拖动/滚动冲突 |
| C4 | 路线归属与目录入口 | 将物理路线明确为控制变量与测量的方法路线，纳入浮力并说明与透镜/单摆的连接；四空间目录继续可直达；浮力/单摆的独立页面也有连贯入口。路线全部来自真实实验目录 |
| C5 | 首次入口的信息层次 | 卡片标第一任务与必要知识，高级解释按需展开；首次目标可达且不隐藏模型限制。预计时长在真实试用后再决定是否发布 |

## 6. D 批：十二个实验的迁移任务

统一交互约定：先留下预测，允许实际操作，再指出一条证据；不强制写长文，不用全站积分替代理解判断。自动判定限于模型可计算的条件，学生解释由试用观察核验。

| 实验 | 新条件或反例 | 反馈应引导查找的证据 |
|---|---|---|
| 浮力 | 固定浸没体积，只改变液体密度 | V排、ρ 与 F浮；明确此任务没有改变浸没后深度 |
| 单摆 | 固定角度比较质量；再把10°换70° | 两组实测周期；小角近似与非线性理论值的区别 |
| 透镜 | 无预设做两组实像调焦，再找虚像 | 光屏与理论像面、实际光线与反向延长线 |
| 面积 | 换非3/4/5边长，复述一般论证 | 两种拼法同外框、全等三角形消去；sqrt 数值核对不是证明 |
| 截面 | 五边形继续平移，预测哪个顶点消失 | 被切原棱、交点合并与平面位置 |
| 莫比乌斯 | 比较0/1/2半扭转，先预测再逐条走切边 | 完整连通带数、边界数、绕中心圈数分别命名；不用颜色作唯一依据 |
| 月相 | 满月离开地影后，满月还在吗 | 受光比例与本影覆盖分别变化；不是每次满月都有月食 |
| 卫星 | 同速度大小改方向，得到负能量穿地轨道 | 初始高空条件、近地点与地球半径；负能量不能保证安全绕行 |
| 三体 | 八字轨道能说明所有三体都稳定吗 | 同刻轨迹差异与各自能量误差分列；有限时域结果的结论范围 |
| 桥梁 | 同方案载荷翻倍，再改偏侧受载 | 支座反力的平衡与对称条件；压杆红色不等于断裂，稳定不等于材料安全 |
| 重心 | 全部质量加倍与只加配重有何不同 | 复用同比加倍验证，增加只改配重的预测；重心加权位置与左右倾斜差异 |
| 齿轮 | 只换中间轮；扭矩3倍是否创造能量 | 首尾速比/方向与理想 P=τω；转速降低对应扭矩增加，非实际效率测量 |

优先将 A 的首次任务接到上述迁移，再补其余实验。轨道两组同速不同方向快照、桥梁等材料长度方案对照与偏载、齿轮预测后揭示读数，归入 D 的对应实验，不额外堆叠自由参数。

## 7. 验证计划与交付定义

每个交付包必须包含可追溯需求、科学判据、对应交互验证和边界说明。纯文案/定位调整用浏览器核验；计时、几何来源、序列化与挑战来源等逻辑需针对实际风险测试，避免只测试代码的同义实现。

实施时运行相关逻辑与浏览器检查，再运行构建；A 批回归既有透镜首次任务/持久记录、月相挑战、浮力、单摆和截面。禁止把本轮文档审查写成已经通过上述测试。

真实学生观察使用报告 §7 的两轮方案：每人先做一个熟悉、一个陌生主题；第二轮补覆盖并针对卡点复测。不要求每人一次做完十二实验。建议记录模板：

| 字段 | 记录要求 |
|---|---|
| 基本条件 | 匿名编号、学习经历、设备、页面版本、任务编号 |
| 过程 | 首次有解释的变化所需时间、实际操作、求助位置与原话、手机往返次数 |
| 证据理解 | 固定量/改变量是否说清；解释编码0仅结果/1关系/2引用证据/3条件或反例 |
| 迁移与回访 | 新条件预测、操作后是否修正；间隔后能否恢复条件并解释 |

先记录基线再制定目标值，不编造完成率和耗时承诺。小样本用于发现卡点，不对整体教学效果作统计推断。若学生无法理解新提示，应修改提示或任务，而非继续增加提示层级。
