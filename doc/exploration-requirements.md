# 六个探索实验：需求

## 范围与产品方向

首页已获用户认可，下一阶段优先建设内容。四个空间各两个独立实验，共八个；保留浮力与单摆，新增面积搬家、立方体截面、卫星发射、三体对照、桥梁挑战、齿轮工坊。莫比乌斯带下一轮再做。暂不建设课程、账号和学习记录。

实验不套统一页面模板：拼图台、双视图剖切台、发射任务台、双轨迹对照台、桁架施工图和机械组装台分别服务不同操作。共同底线是可操作、有观察证据、解释模型和支持再次挑战。

## 实验验收条件

| 实验 | 必须提供的操作 | 证据与挑战 |
|---|---|---|
| 面积搬家 | 改变两直角边、选择/拖动/旋转四块三角形、吸附、提示与重置；键盘可完成 | 两种等面积大正方形，扣除同样四块三角形后 c²=a²+b²；改变比例再完成 |
| 立方体截面 | 方位角、倾斜角、偏移，三角形/正方形/六边形预设 | 三维投影与平面截面同步显示，顶点数来自实际求交；找出五边形 |
| 卫星发射 | 速度、方向，坠落/圆轨道/逃逸预设，发射、暂停、单步、重置 | 轨迹、时间、半径、速率、能量；碰撞停止；挑战保持有界轨道 |
| 三体对照 | 八字/敏感初态预设，扰动量，开始、暂停、单步、重置 | 两个独立积分系统、同尺度对照，真实位置差与能量误差；近遇暂停 |
| 桥梁挑战 | 选择节点添加/删除杆件，裸框/桁架预设，载荷与受载节点 | 刚度求解，失稳检测，拉压颜色、位移、反力、材料长度；挑战少材料稳定结构 |
| 齿轮工坊 | 两/三齿轮切换、齿数、输入转速，开始、暂停、单步、重置 | 转向、速度比和理想扭矩；中间齿轮影响方向但不改变首尾齿数决定的比值；挑战三倍减速 |

## 通用要求

- 独立页面全部由目录真实链接，不用假卡片凑数；数量由元信息派生。
- 320/390px 无横向溢出；指针拖动与点击适配触屏，所有操作有键盘入口。
- 动画初始暂停，显式开始；隐藏标签和离开页面暂停，恢复后不自动继续。
- 无脚本仍有静态示意、原理、模型边界和启用脚本提示。
- 数据与图形由同一纯模型驱动，数值积分与结构求解需测试；原有实验需回归。
- 用户需求、设计、接口、操作和验收文档统一在 doc/。OpenSpec 保留流程文件及正式验收契约。
