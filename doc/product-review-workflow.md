# 实验效果核验：精简流程

日期：2026-10-18。本轮只简化核验材料，不修改产品代码。

使用 [Excel验收表](assets/product-review/experiment-review-140.xlsx)。140个实验，每项只需回答两个问题，有问题再补一句意见。

## 你只需要判断什么

| 问题 | 选项 | 判断依据 |
| --- | --- | --- |
| 有帮助吗？ | 有帮助 / 一般 / 没帮助 / 未体验 | 是否让你更直观地理解这个问题？无需复述原理，也不考核知识。 |
| 吸引人吗？ | 吸引人 / 一般 / 不吸引 / 未体验 | 是否愿意继续尝试，或推荐给别人？ |
| 哪里最需要改？ | 有问题时写一句即可 | 例如“看不出变化”“三维没帮助”“不知道怎么开始”。无需给修复方案。 |

表格共8列：编号、空间、名称、URL、简短体验提示，以及以上3个反馈栏。黄色区域用于填写。表头与前四列冻结，可按空间或未体验状态筛选。

## 怎样使用

1. 点URL打开实验，按自己的兴趣体验。“试一试”只是提示，不要求逐步打卡。
2. 填两个评价；有问题时写最主要的一处即可。不必测遍控件、分别验收二维与三维，或额外换手机与浏览器。
3. 保存文件，告诉助手已填哪些编号。文件在当前工作区即可直接读取；在别处编辑则放回工作区或发回对话。

实验打不开或做不下去时，直接写明情况；无法判断帮助与吸引力时，可以保留“未体验”。截图、视频、设备信息、日期、复现报告均不必逐项填写，确实影响定位时再补充。

每次体验几项即可，不必一次完成140项。也不必另填总体结论、背景检查或修复状态。

## 哪些工作由助手承担

页面与控件可用性、数据与已建科学关系的回归、视图状态同步、背景内容是否存在、布局与遮挡等基础检查，由助手使用工具处理。科学边界、历史准确性及工具难以判断的表达问题，由助手进一步审阅；不把“工具通过”或“大概率没问题”当作全部正确的证明。

这些项目从人工必填表移除，但不降低产品要求。你体验时偶然发现相关问题，顺手记在意见栏即可。

收到反馈后，助手保留原话、整理问题、修复并执行必要回归，再提供简短复验步骤。不会替你填写“有帮助”或“吸引人”，也不要求你维护工程缺陷状态。
