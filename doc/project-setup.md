## 本轮设计决定

站名暂用“科学探索实验室”，未决定域名。主站面向青少年自由探索，兼顾家长和教师共同使用。空间暂沿用交接建议的物理、数学与几何、宇宙与三体、空间与建造四类。

首页的任务是让访客从一个可操作的现象出发，进入实际实验。采用蓝白科学馆展台：天空白 `#fbfdff`、仪器蓝 `#096dbb`、深蓝文字 `#153b56`、浅天空蓝 `#edf6fc`、阳光黄 `#ffdc61`、轨迹青绿 `#188d83`。标题采用较粗的 Noto Sans SC Variable，正文用同一字体的常规字重，仪器和英文标注使用 IBM Plex Mono。

首页特色是可调整摆长并启动/暂停的单摆仪器预览。主视觉直接展示可改变的科学现象；四个空间采用项目内绘制的 SVG 仪器展台，不同时启动多套三维场景。首页只加载轻量脚本，Three.js 只在实验页面加载。减少动态设置下默认静止，用户可显式开始运动；手机和键盘都有操作入口。

```text
品牌 + 导航
提出问题 / 探索入口 | 可操作的单摆预览
四个空间展台（开放数量与筹备状态）
真实可用实验
一次对照实验的邀请
模型与来源
```

未采用宇宙题材的暗色主站和无意义动画。单摆实验内保留原有深靛蓝仪器环境，保持成熟实验交互质量。首页预览明确说明小角度近似及简谐示意，完整单摆仍使用非线性模型。

## 工程边界

Astro 静态站、原生 TypeScript、Three.js，Node 24+。模型与视图继续分离。`src/data/labs.ts` 维护真实实验与空间元信息，计数、首页和目录统一派生。暂不引入跨仓库共享包、后端或账号系统。未指定真实域名前不生成虚假站点地址。

操作与验证命令见根目录 README。旧仓库的测试通过记录没有当作本仓库的验收结果，实验文档中的旧站数量和旧 OpenSpec 命令已移除。

## 本仓库验收

在 Node 24.19.0 下完成：

- `npm test`：7 项模型测试全部通过。
- `npm run build`：Astro 检查 0 错误、0 警告、0 提示，生成 9 个静态页面。
- 生产预览上的 `npm run test:browser`：主站、浮力和单摆全部通过，含 320/390px、键盘、减少动态、无 JavaScript 目录、无 WebGL 降级；单摆额外覆盖真实拖拽、实测周期、对照、能量和任务反馈。
- 主站首页确认不加载三维运行时，所有筹备空间均可进入说明页并返回已开放实验。
- 桌面与手机截图已输出到 `test-results/`；视觉复核修正了首页 SVG 默认填充问题。
- 依赖安装发现 `http-cache-semantics` 间接依赖的已知问题，已升级至兼容修复版本；联网审计为 0 漏洞。

Three.js 公共包约 560 KB，构建保留超过 500 KB 的体积提示；它只由实验路由加载。后续按实测加载体验决定是否进一步优化，不通过抬高警告阈值掩盖体积。

本机默认 Node 为 23，本轮通过 `/usr/local/Cellar/node@24/24.19.0/bin` 使用 Node 24。默认 4321 端口已被其他服务占用，本轮生产预览实际运行于 `http://127.0.0.1:4323`，浏览器验收通过 `BROWSER_CHECK_URL` 指定该地址。
