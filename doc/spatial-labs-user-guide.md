# 三维纸带与透镜操作指南

## 透镜
进入 `/labs/lens/`，先用默认情景看光屏上的倒立 F。拖动蓝色光屏，观察图案变模糊，再移回清晰处；理论像距始终 15 cm。手机可用滑块或“光屏靠近/远离”每次 0.1 cm 微调。

拖动金色物体改变物距，或选择远处风景、等大、投影特写、焦点、放大镜。点击“寻找清晰像”观看只移动光屏的标准演示，再自己做挑战。暂停按钮可以继续，手动改变条件会停止演示。

空白处拖动转动视角，滚轮/双指缩放；也可点击立体全景、正视光路、俯看、光屏特写。聚焦画布后方向键转动；所有实验参数仍可用滑块键盘调整。二维光路保留直接拖动和箭头键，每次 0.5 cm；滑块每次 0.1 cm。

放大镜情景出现正立虚像观察窗，光屏显示不可投屏。虚线只是反向追溯。记录按钮最多记六组，保存在此浏览器并可逐组恢复；存储不可用时会提示仅保留当前页面。

## 莫比乌斯带
进入 `/labs/mobius/`，默认一次半扭转。先点击“沿纸边走”，再“走到起点”。走一圈到起点的另一侧，两圈才回到出发位置；进度 50% 对应一圈。普通纸环和双半扭转带一圈返回。

暂停/继续可停住观察，进度滑块可直接定位。拖动空白转动纸带，方向键/视角按钮也可观察接缝与遮挡。

先猜中心剪开后的条数，再点击剪开。切缝会逐段推进，可暂停或用工作台下的“中线剪切进度”手动观察；100% 时才揭示结果。减少动态模式需手动推进。一次半扭转仍是一条双面带，零次变两条，两次变两条套连带。剪完后可选每条完整纸带，沿纸面、原边或新切边独立追踪；莫比乌斯剪后的一条带两圈返回，其余每条一圈返回。恢复未剪或选择其他纸带继续比较。详见 [重心与纸带打磨说明](balance-paper-polish.md)。剪后面数是每条带的面数，边界是全部带的总条数。

按页面实体活动用三张长纸条制作零、一、两次半扭转，画线验证，再沿中线剪开。画面的扩大切缝只是观察示意，不代表纸张实际拉伸。

## 兼容
无 WebGL 或显卡上下文丢失时自动使用二维示意，滑块、演示、预测、剪切和实时数据继续可用。无 JavaScript 时阅读静态图、科学解释与纸条活动。减少动态设置下纸带演示按四个阶段推进；没有自动旋转或自动播放。
