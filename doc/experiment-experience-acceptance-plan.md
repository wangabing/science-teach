# 从“测试通过”到“学生能完成实验”

2026-10-18。由“潮汐撕裂没有演示入口、三维只有相机操作”的反馈触发。开发应主动承担排查和验收责任，不依赖用户逐个替产品找问题。

## 已确认的验收漏洞

旧流程重点检查页面、控件、同源读数、空间画布与几何散列。它能防止崩溃和状态不同步，但无法证明主现象可见、入口好找、操作有意义。潮汐的固定球体加附属仪表就绕过了这一标准。上一轮报告中的“已核查”不代表教学体验合格。

## 本轮验收边界

按用户2026-10-18的要求，先完成产品实现与测试巡检修复。下表前两层及浏览器模拟操作作为本轮产品门禁；真实学生任务、教师教学复核移至推广后沟通反馈，单独记录，不阻塞开发，也不冒称已经完成。

## 四层验收

| 层次 | 必须回答的问题 | 方法与交付 |
| --- | --- | --- |
| 全站自动巡检 | 能进入吗？控件可用吗？报错/溢出/遮挡吗？双视图可打开吗？ | 固定生产构建，批量遍历全部路由；每项保留结果和错误 |
| 科学现象联动 | 改变条件后，主装置、受力、运动或构造是否正确变化？哪些量应保持？ | 控件端点与情景比较，区分数字、文字、主图和空间几何；独立公式或不变量断言 |
| 学生任务验收 | 能找到开始入口、做一次探索、保存证据并解释结果吗？ | 每项一条具体任务，实际执行，记录桌面/手机操作视频与结论；没有执行就记待审 |
| 教学质量复核 | 科学边界清楚吗？适合相应学段吗？三维有帮助吗？ | 人工审阅与师生试用，核对北京所用教材/版本；不能由脚本替代 |

不能强制所有实验播放动画：静态几何、稳态电路可以通过有效操作完成探索。需要过程的实验应有演示或明确的启动动作。三维相机操作与实验对象操作必须分开记录；有canvas、能旋转都不自动算可操作实验。

## 缺陷分级与关闭条件

| 等级 | 问题 | 关闭所需证据 |
| --- | --- | --- |
| P0 功能阻断 | 无法打开、报错、关键操作无法完成、科学关系错误 | 可复现失败、修复、相同任务回归和相关范围回归 |
| P1 现象不足 | 只有读数变化、核心装置固定；需要过程却无启动；关键证据缺失 | 操作前后画面/数据、独立科学断言、完整任务 |
| P2 操作障碍 | 入口难找、相机和实验操作混淆、手机遮挡、键盘不可达 | 桌面/手机真实操作记录与可访问性验证 |
| P3 表达优化 | 比例说明、标签、取景、对比不清晰 | 修改后的图像与人工审阅 |

筛查中的“风险”是待确认线索，不直接等于科学错误。例如质量不影响自由落体加速度是合理不变量；需要说明，并检查质量是否对相关证据产生适当影响。全图散列变化也不能证明现象正确，附属仪表可能掩盖静态主图。反过来，温度计、光谱或场的读数本身也可能是核心证据；应结合仪表和曲线判断，不能机械要求球体变形。

每项审阅记录包括：路由、学段/目标、首个动作、操作步骤、预期现象与不变量、二维用途、三维用途与直接操作、独立验证关系、移动端/键盘、保存恢复、边界、证据路径、问题等级、处理状态、审阅人和时间。自动检查、学生任务、教师复核分别标记，不能互相代签。

## 潮汐撕裂的完整验收任务

1. 在装置旁找到“演示：逐渐靠近”，启动扫描；距离、小天体位置、潮汐箭头、曲线光标与读数一起变化。
2. 暂停后单步，确认保留条件；扫描只是控制变量的演示，不是实际公转/下落时间。
3. 直接拖动二维小天体改变距离；切换三维后拖动同一对象，空白处拖动仅旋转相机；切回二维保留条件，撤销可恢复。
4. 固定质量、半径、密度，比较1500与750千km；潮汐加速度应为8倍，自引力不变。注意旧情景曾把千km误写为km。
5. 改变密度，比较自引力及流体Roche边界。局部力比等于1与流体Roche极限不是同一个判据。
6. 保存两组记录并核验独立任务；自动演示/预设不计完成。
7. 在320/390px、键盘、减少动态和WebGL失效时完成对应操作。读出小物体近似、屏幕对数距离、放大尺寸和箭头缩放的边界；页面不宣称求解碎裂动力学。
