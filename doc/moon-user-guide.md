# 月相与日月食：操作指南

打开 `/labs/moon/`。先看右侧（手机下方）的月盘，再动左侧月球。装置图的距离压缩了，月盘是从地球看到的放大视图。

## 三分钟探索
1. 点击“演示：一轮月相”。观察右侧亮面先增长，再退去。可以暂停，也可以随时改变参数接管。
2. 点击“满月，无月食”，再点“月全食”。两次受光比例都接近 100%，区别是后者进入地球影子，月面变暗红。
3. 比较“日全食”与“日环食”。距离变远后，月球看起来更小，太阳盘留下亮环。太阳盘只代表地球金点这个理想观测位置，并非全球所见。

## 亲手操作
- 在三维里直接拖动月球沿轨道移动；空白处拖动转动视角，滚轮/双指缩放。俯看轨道更方便沿轨道拖动。聚焦三维画布后，方向键转动相机。
- 切换二维后仍保留条件，拖动月球或聚焦月球用左右键移动，每次 1°。滑块和 0.1°/1° 微调适合精细对齐与手机操作。
- 八个月相按钮只改变月球位置，不会替你改变倾角与交点。改变“交点方向”时观察黄纬及阴影截面：偏离交点的满月可能错开地影。
- 倾角默认真实的 5.145°，改为 0° 可比较共面理想情况；地月距离会改变月球在太阳盘前的角大小。

## 预测与挑战
先预测“每次满月都有月食吗”，再观看“满月为什么没被遮住”。演示只改变交点方向，保持月球满月位置、距离和倾角，便于控制变量。

点击“准备月食挑战”，保持倾角 5.145°、距离 60.27 R⊕，调整交点到 0° 或 180° 附近，再微调月球位置；让本影覆盖整个月盘后检验。把倾角降到 0° 不能完成挑战。

## 如何读证据
- k 是普通月相受光比例，不是照片平均亮度；月全食时 k 仍接近 1，但直接阳光被遮住。
- β 是月球离黄道面的角度；交点上 β=0。
- 太阳被遮挡比例属于地球金点视角；满月侧不发生该点日食。
- 阴影截面的内圈为本影、外圈为半影，浅色小圆是月球；按实际比例绘制。月球在太阳一侧时这幅月食判据图淡化。
- 本页“天数”只是平均朔望月教学进度，不对应真实日期，不能用来预报食。

## 室内复现
用固定室内灯、浅色小球和自己的眼睛重做月相；让球稍高于头部，避免身体影子误当普通月相。背对灯时将球从高处移入头部影子，比较满月与月食。真实日食不能直视太阳，不能用普通望远镜直接观察。

三维失败会自动切换同状态二维；纹理失败仍有球面光照示意。减少动态设置下演示分阶段呈现，无脚本仍可阅读静态图和实体活动。

手机滚到参数区、画面离开视野时，底部观察条同步显示受光比例与当前事件。点击“回看画面”可回到双视角观测站，参数保持不变；看画面或读下方解释时观察条隐藏。
